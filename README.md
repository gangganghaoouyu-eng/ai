# 星栀写作插件

版本：**2.0.2**。

面向中文连载小说创作，包含三个技能：

- **新书构建**：从题材、世界观和人物设定，到全书大纲、卷纲、章纲及节奏安排。
- **正文写作**：按本书人设、视角、阶段和场景创作、续写、扩写或润色正文。
- **拆书分析**：分析指定作品的结构、人物、节奏、文风与格式，提炼原创写作方法。
