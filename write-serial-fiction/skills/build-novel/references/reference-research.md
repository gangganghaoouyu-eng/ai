# 参考研究与原创方向

当用户提供同类作品、希望先拆书再建新书，或要求联网寻找参考资料时读取。参考研究可在构建前进入，也可中途补充；不要求先完成设定问卷。

## 来源与实际范围

读取用户明确提供的原文、文件、链接或指定作品。只给书名时，用户要求分析这些作品即按需调用实际联网工具定位相关资料并核实作品身份；同名作品或版本歧义会改变分析时只问最少的必要问题。没有可用联网能力时如实说明，并利用已有资料，不假装查到。

优先作品原文、作者/官方平台资料；公开简介、章节目录、访谈和可靠介绍可补作品定位。保留作品、作者/版本、来源、实际读到的章节或页面和缺口。联网的事实性结论就近附来源，推论明确为分析，来源间冲突不悄悄合并。

书名、搜索摘要、简介、评论、目录不能替代实际章节。仅有简介时只能分析简介能支持的目标、人物定位和核心矛盾；具体文风、每章节奏、长程铺垫与回收需要对应原文。节选只支持相应范围，不声称读完整书或掌握全卷。不能承诺搜索到未公开的全书，不捏造销量、追读或“爆款”成因。

仅核实作品身份或补简介时可用公开资料；需要拆实际原文时读取 [文章拆解与写法学习](../../analyze-writing/SKILL.md) 及其证据规则。这个构建支线默认要求有范围的分析和原创方向，不额外强制试写、永久规则提案或完整学习报告；用户要求参考文风例文时转入该技能已有参考示范路径。单独拆书请求仍按拆书原有规则执行。

## 多作品比较

依据实际范围选择有证据的维度，不强行补齐：
- 核心看点、主角目标、起始处境与失败代价。
- 世界和能力规则怎样创造机会及阻力。
- 主角、同伴和对手的目标、资源、关系与行动理由。
- 主要矛盾的形成、阶段结构、长期剧情的持续方式。
- 压力、准备、关键选择、回报与实际后果。
- 事件、信息、情绪和回报节奏，章末承诺及下一章响应。
- 开篇与信息呈现；有原文且用户需要时再分析文风格式。

多本作品可用比较表，但各自标清阅读范围和待验证判断。不用同题材标签证明结构相同，也不把混合来源写成某一本的做法。

## 提出可选择的创新方向

先用来源支持的方法与适用前提提炼共同规律和不同解法，再给2—3个具有实质区别的原创方向；用户指定数量时服从。

每个方向说明：
1. 参考了什么可迁移机制，以及实际来源范围。
2. 改变的目标、身份、关系、资源、能力代价、信息条件或结果。
3. 新变化怎样产生核心矛盾、人物选择和后续剧情。
4. 适合的阅读体验、长篇持续条件及具体代价/难点。

原创人物、专属规则和情节因果重新设计；不以换名保留参考作品整条情节，不把多个作品特色拼在一起就宣布创新。不要保证“全网从未出现”或商业成功。

用户可以选择、混合、否定方向或补充自己的想法。按最新回答融合并指出相互冲突的条件，选定核心方向后继续主体设定或相应纲层，不重新问已知题材和书名。

## 与正式规则的关系

本轮指定的参考机制作为本书方案，是否采用由用户的创作决定体现；不因用于本书就写入插件通用规则。没有明确要求使用的分析候选不自动作为后续默认。若用户明确要将学习成果更新插件，则另依拆书技能的具体提案、适用范围和授权流程执行。

不得自行后台持续搜书、自动学习所有附件、永久保存他人全文或宣称跨会话自动记忆。用于本书的构思摘要只保留必要来源、已选方案和范围。
