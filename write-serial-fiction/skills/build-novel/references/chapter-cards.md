# 章纲卡与场景展开

按用户要求的深度选择有关字段，不为填表新增情节。连续章段先列核心因果，再展开本次需要的章；章纲是未来计划，不能成为阶段档案里的已发生事实。

## 可直接写作的章纲卡

| 字段 | 应写出的内容 |
| --- | --- |
| 章序、章名与接点 | 正式或暂定标记、适用时间、地点、在场者、前文未完成动作或话题 |
| 视角与知情 | 本章允许的视角、本场心理主角、各人实际知道或误解什么 |
| 当下目标与阻力 | 人物希望得到什么，谁或什么使它不能轻易完成 |
| 核心变化 | 本章结束后必须出现的选择、信息、关系、资源或实际处境变化 |
| 场景顺序 | 每场怎样进入、关键刺激、对白或行动、结果以及转场原因 |
| 关键回应与行动 | 分歧的具体对象、回应如何改条件、选择怎样执行并产生后果 |
| 情绪发展 | 触发依据、即时反应、回应后的变化与尚未消退的余波 |
| 信息、伏笔与回响 | 埋设、延续、部分揭示、回收或旧事呼应；谁能够看到及何时获知 |
| 回报与代价 | 承诺兑现了什么，实际得到或失去什么，留下什么责任或限制 |
| 收束与接续 | 本章核心场景如何完成，具体待办是什么，下章怎样响应 |
| 篇幅与主次 | 哪场充分展开、哪场压缩、各部分大致分量及容量冲突 |

完整卡不要求固定场景数。关键台词可以写出原话或意思要求，不能替每个人预写整场长谈。正式章序未知时不编造；草拟章名允许明确标为暂定。

## 把事件标签展开成因果

“争执后决定合作”需要落实：双方想保护的利益、不同条件、导致争执的事实、怎样尝试、哪次回应改变条件、谁作决定、执行时付出的代价。结局已指定时保持结局，允许过程有有限失败和未消散情绪；不强迫所有人当场想通。

独立原创示意：

- 接点：两人带着货单到仓库，发现值班人只有一位；车辆必须在关闭前离开。
- 目标与阻力：承运方只负责送到门口，收货方缺人装卸；双方都不愿承担额外损耗。
- 核心谈话：围绕等待时长、装卸人员和缺件责任提出条件。收货方提出自己找人，但司机须留场完成交接；承运方增加超时费用。
- 行动与变化：两人接受明确费率并开始卸货，合作范围落实；司机发现实物与单据不符。
- 收束与承接：本章完成协议和第一批交接，以具体差额引出核实；下一章先处理差额，不再重谈已确定的等待条件。

这是方法示意，不是固定事件或通用章纲配方。真实写作的物件、身份和时间限制来自本书。

## 场景类型与表达机会

交涉给重要异议及针对回应留空间，写明条件变化；危险场景优先行动、位置和即时后果，必要警告与协同随时间压缩；暧昧可用有回应的靠近与选择推进；独处可用事务、记忆触发与决定推进。各类均依据人物能力、职责、关系和余力安排，不用相同动作证明人设。

同一连续场景保持本书规定的心理与视角范围。章纲可注明作者控制信息，但必须把它与场内人物所知分开，不能让正文作者照抄幕后动机进入限知场景。
