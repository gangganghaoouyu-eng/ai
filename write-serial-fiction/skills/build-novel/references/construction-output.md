# 阶段成果与持续修订

按当前范围和用户希望的深度逐步形成成果，不在每轮重新打印完整设定，不把填满表格当成完成构思。

## 分批成果

| 层级 | 交付内容 |
| --- | --- |
| 一页概念卡 | 题材、暂定书名或暂未命名、一句话故事、核心看点、主角目标、主要阻力；资料不足时只写已有及暂定内容 |
| 主体设定 | 与剧情有关的世界规则、主要人物与关系、可选能力及边界、视角和关键创作约束 |
| 全书大纲 | 主线因果、关键选择与转折、重要支线、人物变化、终局方向及必要伏笔 |
| 卷纲/阶段纲 | 各阶段目标、阻力、尝试、转折、兑现、代价及下一阶段的成因 |
| 章纲/细纲 | 按当前需要展开章序接点、场景次序、变化、知情、情绪、回报及承接 |

构思有足够方向时先给简短雏形：从哪里开始、主要阻力、人物选择、大致结果及关键情绪变化。还没有卷章条件就先停在相应层级，不冒充完整全书规划。用户说“先出一版”时立即交付当前范围的暂定版本。

用户要求某层成果时按其深度直接生成；已回答内容不重新调查，不因只有部分设定而强制完整问卷。根本缺少故事输入时只问必要问题，次要缺口补成建议。

## 当前构思状态

阶段性区分：
- 用户已确定：明确表达、选择或修订的内容。
- 助手建议：为填空或帮助比较提出但尚未选定的安排。
- 待定：尚未回答、没想好、已跳过或存在关键冲突的内容。
- 已发生事实：仅适用于实际写过的正文，与未来规划及人物认识分开。

只展示会帮助当前判断的状态变化，不每轮复制四份清单。用户说“继续”只授权当前流程继续，不等于批准全部建议；“构思完成”不把标明待定的内容自动变成事实。

## 接入修改

接受选项、自由文本、引用问答和后续聊天中的补充；用户明确文本及修订优先于选项隐含假设。先整合额外补充，再决定下一问。

修改题材、世界规则、主角目标、关系或能力时，回看依赖的设定、大纲节点、卷目标和相应章纲。指出具体影响，提出融合或替换方向，保留不受影响的已确定安排。小缺口可先给暂定建议，关键互斥条件需解释并问一个最重要的问题。

用户希望提问就继续讨论；希望直接生成就按现有内容输出。整理或完成指令不追加一轮是否结束的确认；只改一处时交付改动及必要影响，不重做全书。

## 接续与交付范围

按用户需要给简短构思摘要，包含当前模式/范围、已确定内容、关键建议、待定点、最近修订和下一步位置，便于在当前对话继续或带到另一次对话。摘要不承诺永久记忆，不要求每次都建文件。

用户请求文档、全文圣经或存档时依实际可用的宿主文件能力完成所需成果；没有要求时不额外建立阶段档案或保存流程。具体书籍内容不自动写成插件规则。参考来源的分析状态与本书采用状态分别记录。
