# 情绪、关系、环境与混合转变

从 [声线总规则与索引](character-voice.md) 匹配类型后，合用对应模块的本场情绪与场景调整，再按本场的环境、关系、强度或情绪转变读取有关部分。小说当前阶段与知情边界优先，不因为参考库中有某种状态就编造刺激或升级关系。

## 情绪与状态范围

各模块均展开十五项：高兴、期待、害羞与心动、失落与难过、委屈与受伤、悲痛与重大失去、愤怒、吃醋、害怕、焦虑与不安、愧疚与后悔、感动与接受安慰、失望与信任受损、疲惫与压力、安心与恢复。

疲惫与恢复属于影响表达的状态。每项均需结合强度：轻微情绪可能只改变一句话；中等情绪会影响交流策略；强烈情绪可能暂时打乱惯常声线。失态必须有足够刺激，恢复也需要时间和经历支撑。

## 回应与恢复速度

按 [回应速度与情绪消化](dialogue-craft.md#回应速度与情绪消化)，把本书当前阶段的性格、关系与刺激强度共同用于回应速度和表达完整度。突发震惊可以造成失语、结巴、误解、改口与必要确认；相同刺激对已有信任、习惯表达的人也可能只改变一句话，不将紧张设为所有人的固定表现。

得到明确回应后，情绪可以继续影响后续措辞、动作与选择。理解事实、接受关系变化和恢复平静可能有不同速度；不为推进剧情让人物立即冷静，也不靠持续索取同样的保证拖长场景。情绪恢复依真实经历和当下余力，不凭一次回应完成长期性格变化。

## 关系与状态调整

| 条件 | 调整重点 | 不应自动发生的变化 |
| --- | --- | --- |
| 初识、陌生 | 以公共事实与眼前事务为主，称呼和个人信息保持分寸。 | 突然交代全部身世、深情保证、使用后期亲昵称呼。 |
| 熟悉、合作 | 可以依共同经历省略背景，提出与实际信任相符的请求。 | 因合作顺利就成为知心人或恋人。 |
| 暧昧、未确认 | 允许试探与含蓄，表达自己的期待而非默认享有关系权利。 | 直接占有、限制交往、把对方沉默当作确认关系。 |
| 稳定亲密 | 能引用共同习惯，坦白需要，仍可保留个人边界。 | 永远互相理解、每轮情话、持续检查身体和忠诚。 |
| 信任破裂 | 原有声线保留，开放程度、配合意愿、称呼与距离发生有据变化。 | 一次拥抱恢复全部信任，或所有旧感情立即消失。 |
| 正在修复 | 对具体改变给出有限回应，允许靠近与顾虑并存。 | 因一句保证跳到关系恢复阶段。 |
| 公共场合 | 发言受身份、在场者与公开信息范围影响，可能克制或维持体面。 | 将私下秘密自然说给所有人，旁人自动理解隐藏情感。 |
| 私下独处 | 有空间谈个人需要，但是否说仍受信任与准备程度限制。 | 一独处就完整坦白所有动机。 |
| 轻微情绪 | 一处措辞、参与意愿或行为变化即可。 | 小事全部升级成争执、崩溃或人生宣言。 |
| 中等情绪 | 可以改变回应策略、延长必要交流、提出选择与边界。 | 所有发言机械扩成长独白。 |
| 强烈情绪 | 惯常控制可能失效，表达可急促、遗漏或暂时无法继续。 | 所有人变成同样尖叫哭泣，完全抹掉身份和经历差异。 |
| 疲惫、疼痛 | 降低行动与表达余力，简化非必要交流，依据已知状态安排。 | 不断重新核对同一症状，或忽然不再受伤势影响。 |

年龄、职业、成长环境和时代背景决定用词。少年、军人、医者、商人、宗门人物不能只凭性格采用同一种词汇；时代不符的网络词与职业不符的术语不进入台词。按 [口语化与人物口气](colloquial-expression.md) 与本场情绪合用，自然保留连接、语气和小修饰。委屈可以使“都、好歹、能不能”带出请求，嘴硬可以使句内临时磕绊，熟悉关系中可以出现口语玩笑；这些只是可选方向，不为每种情绪分配固定词组。

## 表情的显露与收回

需要面部描写时，与 [眼神、唇角与微表情](facial-expression.md) 的有关段落合用。先由对应声线模块和本书资料确认当前情绪，再选择这个人会显露多少、怎样控制、被对方回应后怎样变化。下面只说明表情分寸，不替代各类的十五项情绪规则，也不按面部样子给人物反推性格。

| 已匹配的倾向 | 表情与声线怎样配合 |
| --- | --- |
| 开朗活泼 | 喜悦可以较快带动眼尾、脸颊和笑容；受伤时原本展开的笑可能停住，愿不愿继续接话依对象与信任决定，不要求一直笑或夸张鼓脸。 |
| 内向安静 | 喜悦可以先表现为唇线松开、目光停留稍久，再决定是否分享；难过可以在私人空间显露，也可以直接说清，不绑定低头、躲眼或无声哭泣。 |
| 自卑、缺乏自信 | 接到善意时可以先抿住笑，确认对方回应后才舒展开；受伤时可能试着维持笑容，也能抬眼拒绝。分寸随成长变化，不每次都眼神怯弱。 |
| 高冷、疏离 | 可信对象面前可以眼尾松开、目光变得柔和；受伤时可以收住笑、绷紧唇线，也可能有强烈失态。疏离不等于冷笑、刀锋般的目光或完全没有表情。 |
| 傲娇、好面子 | 高兴时可以压住唇角，压不住后露出笑；委屈时可能先抿唇再开口。是否掩饰依阶段与对象，不固定演成转头、偷笑、再否认。 |
| 幽默、调节气氛 | 玩笑得到回应时笑意可以加深；真正被刺痛时，笑容可变僵或逐渐消失。认真话语接着改变表情，不让悲痛也必须陪笑。 |
| 温柔体贴 | 喜悦与安抚可以表现为眉眼舒展、唇边松开；受伤或拒绝时也可以收回笑容、目光变得明确，温柔不要求一直带笑。 |
| 直率果断 | 喜欢或生气可以较直接显露，表情与明确台词相接；遇到强烈刺激也可能嘴唇颤动或暂时说不下去，不靠瞪眼证明果断。 |
| 理性克制 | 可以先收住唇线、稳住目光，处理必要事务后再显露余波；开心时也能自然笑开，不以面无表情作为理性的唯一标记。 |
| 敏感细腻 | 一句话或互动差异可使自己的笑停住、眼睫垂下，再按实际信息回应；注意到别人的微表情仍只是观察，不能准确读出所有隐秘动机。 |
| 多疑、防备 | 未明信息可以使目光停留、眉间收紧；有效澄清后可继续行动，紧绷未必立即消失。表情不能成为重新盘问同一答案的借口。 |
| 控制欲强 | 未被配合时可压紧唇线、长时间注视，也可以公开维持笑容；反应由当前情绪、权力与现实后果决定，不把压迫感自动写成深情。 |
| 好胜、善妒 | 获得认可时笑意可以明显，被比较时笑容可能停住；同样也能真诚高兴或克制失落，不每次都阴狠斜视。 |
| 自利、趋利 | 有利结果可以让紧绷的脸松开，失利时可以抿唇或收住笑；私人情感也能真实显露，不靠眯眼冷笑证明算计。 |
| 刻薄、轻蔑 | 讥讽时可以单侧唇角抬起、笑与目光不一致；真正受伤时也可能失去这些惯常表现，不让每句话前都挂着冷笑。 |
| 善于操纵、掩饰 | 可以有意维持笑容或选择显露程度，也会真实喜悦、悲痛或失控；当前视角不能从笑容是否对称、是否流泪直接断言真假。 |
| 执拗、偏执倾向 | 遭到反对时可以目光久久不移、唇线绷住；遇到关键事实时也可能松动或避开视线。变化须有经历支撑，不用固定狠戾眼神代替执念内容。 |

公开场合、陌生关系、身份责任和危险可以限制显露，私下安全与信任可能增加表达，但不能一律套用“公开忍住、私下崩溃”。混合情绪可以使眼里有泪而唇边有笑，也可以使笑意出现后又被压住；只写实际发生的变化，不在动作后宣布人物已恢复信任或作出隐藏决定。

情绪持续时，不每隔几段重新描摹同一层泪光或同一处绷紧的嘴唇。让表情的后续变化承接新的话语、行动和现实刺激；变化不明显时可以转回交流或事务，不能为了描写而不断加重哭泣、怒气或失态。

## 场景与环境怎样改变表达

先保留人物基本声线，再根据当前情绪的触发原因、现实条件和对方刚刚的回应调整。场景不把性格换掉：开朗者在危险中可以简短求助，高冷者面对必要解释也可以说完整的话，幽默者在重大失去时可以不再开玩笑。具体差异见各性格模块的“场景中的声线调整”。

| 场景条件 | 对表达的影响 | 仍需保留的边界 |
| --- | --- | --- |
| 即时危险、战斗、逃生 | 优先警告、位置、限制、求援和可执行协同，缩短非必要话题。 | 知情与专业能力不凭空提高；不同人保留不同关注点、称呼和求助方式。 |
| 公共、多人在场 | 依身份与公开信息选择称呼、措辞和暴露程度；可以暂缓私事。 | 不把旁人当作不存在，不因公共场合就让所有人冷淡或使用官话。 |
| 私下、相对安全 | 有空间说理由、需要与顾虑，能否说仍依信任、习惯与准备程度。 | 独处不自动促成坦白、表白或关系升级。 |
| 谈判、利益交涉 | 围绕条件、成本、筹码和边界回应，情绪影响策略及措辞。 | 不人人突然擅长完整分析，不因愤怒或吃醋遗忘既有目标。 |
| 日常、工作与分工 | 手头事务给谈话入口，邀请、建议、拒绝和协作推动下一步。 | 不重复核对已明确事项，不把职业知识写成无交流理由的讲座。 |
| 调查、询问与证词 | 依据可用信息选择问法，分清观察、传闻、推测与已证实事实。 | 类型不赋予读心能力，不用多疑反复审查同一答案，也不让操纵者必然成功。 |
| 暧昧、试探与亲密 | 主动程度、称呼、请求大小及动作距离依当前关系调整。 | 不默认拥有恋人权利，不用动作替对方同意；已经可感受的意思不重解释。 |
| 争执、道歉与修复 | 对具体行为、需要和边界回应，允许有限接受、拒绝与暂缓。 | 原有性格仍可辨，伤害不凭一句道理或一次接触全部解决。 |
| 悲痛、独处与等待 | 余力与触发点决定能否说、做什么，行动和心理可以承担主要变化。 | 不强迫热闹、不迫使人物总结失去的意义，不硬添对白。 |

同样情绪在不同环境中的表现可以相反，但需有本书依据：公开场合暂时压住不悦，私下再提出具体界限；逃生时先服从有效协同，安全后再表达害怕或反对。不能只写“他忍住了”然后旁白解释全部内情，本场心理主角之外的人物依旧通过可观察的表现呈现，不由旁白揭晓其隐秘判断。

对方每次有效回应都可能改变情绪、开放程度与下一句内容，也可能需要时间才能被接纳。答复明确且含义被理解后，沿用事实继续表达、行动或暂缓决定；情绪余波仍可存在，不为持续表现吃醋、自卑、关心或防备重新索取相同保证。

## 混合情绪与转变

一场交流可以先高兴后失落，也可以心动与不安并存。把转变落在人物实际得到的信息、对方的回应或发生的事上，不在每轮突然切换人格。

| 组合或转变 | 可以怎样展开 | 留白与边界 |
| --- | --- | --- |
| 高兴中带不安 | 人物愿意参与，却对一个尚未确定的条件提出问题；确认后继续准备。 | 不将不安写成永远不能满足的保证需求。 |
| 心动中带自卑 | 想靠近，同时降低自己的请求；明确善意出现后，可以接受一小步。 | 不每次都否定对方回应，不让旁白替他确定对方心意。 |
| 愤怒中带委屈 | 先说越界行为，再在回应中暴露自己被忽视的具体需要。 | 关键话题展开，不能只靠哭泣或拥抱结束。 |
| 吃醋中带好面子 | 从安排或被忽略的事切入，依据回应决定承认多少在意。 | 不永远否认再追问，不重复审查关系。 |
| 害怕中仍要负责 | 报告自己的限制，同时给出能力范围内的行动。 | 责任不使危险和体力限制消失。 |
| 愧疚中仍有防备 | 承认自己的行为，却暂不愿谈另一个秘密；责任范围与秘密分开。 | 不能借防备逃避明确责任，也不强迫当场交代全部过去。 |
| 受伤后接受安慰 | 有效帮助使人物愿意接下一句话或接受一项实际照顾。 | 可暂时缓解，未解决的矛盾和旧伤仍保留。 |
| 失望后有限修复 | 对一件真正兑现的事重新开放一点配合。 | 不由旁白宣告全部信任恢复。 |
