# 高冷、疏离：人物声线与情绪表达

依据本书已确认的人物设定和当前阶段匹配后，读取本场相关情绪行及场景调整，同时保留基本声线、关系阶段与避免写偏说明。表中方向不要求全部出现，不能成为固定台词和动作。使用方法见 [声线总规则与索引](../character-voice.md)，环境、关系、强度和混合情绪见 [情绪、关系与环境调整](../voice-context.md)。

**适配依据：**人物主动限制亲密、信息与情绪暴露，保持社交距离。与天生内向、临时疲惫、职业场合克制分别处理。

**基本声线：**话题范围明确，措辞有分寸，对必要事项可说得充分。冷淡可以体现在不主动延伸和保留私事，不靠两字台词、傲慢或低沉磁性形容。

| 情绪或状态 | 对白与回应方式 | 行为、节奏与留白 |
| --- | --- | --- |
| 高兴 | 可以明确认可成果，稍多说明一个细节；私人喜悦也可能只向特定对象表达。 | 愿意多留一段时间、接手额外事务；不必突然露出罕见微笑来打标记。 |
| 期待 | 以询问安排、明确时间和表达选择呈现；关系近时可直接说想见面。 | 主动空出日程、提前到场；不假装对一切毫不在意。 |
| 害羞、心动 | 对过分亲近的表达可能谨慎回应，或把话落在具体邀请上；可承认感受。 | 原有距离略有变化，愿意共享物件或空间；不能让旁白读出其全部心思。 |
| 失落、难过 | 少谈私事，但对眼前问题能继续回答；也可能清楚提出独处。 | 结束非必要聚会、改变原计划；不要求所有失落都毫无痕迹。 |
| 委屈、受伤 | 可能先指出事实和越界行为，再说明自己的立场；对可信对象表达更直接。 | 停止原本的配合、收回亲近许可；不以一句冷笑解决全部交流。 |
| 悲痛、重大失去 | 可以保持处理事务的能力，同时在某个具体环节难以继续。 | 整理文件、交接任务时出现真实阻滞；不把克制写成没有伤痛。 |
| 愤怒 | 语气可能更明确，减少礼貌缓冲，提出后果或边界；不必靠威压形容。 | 中断合作、离开位置或接回决定权；后果符合实际身份和能力。 |
| 吃醋 | 可问一次事实，随后表达关系需要或调整安排；是否坦白由阶段决定。 | 参与意愿或距离改变；不自动转成命令、禁足和占有宣言。 |
| 害怕 | 可以用简洁事实求援、明确行动顺序，情绪暴露可能较晚出现。 | 靠近可用出口、接纳援助；不能因冰山标签免疫恐惧。 |
| 焦虑、不安 | 更容易抓紧具体准备，表达时指出未明问题；不能无限确认。 | 缩减变量、提前处理安排；有答案后接受行动中的限制。 |
| 愧疚、后悔 | 可以直接认错并说明修正，不用冷淡掩盖责任。 | 兑现补救、撤回错误要求；不把送礼或保护当成无需道歉的理由。 |
| 感动、接受安慰 | 可能只说一个具体感谢，随后允许帮助继续；熟悉后可坦白脆弱。 | 愿意把事务交给对方、留下陪伴空间；不必用拥抱立刻升级关系。 |
| 失望、信任受损 | 明确收紧交流与合作范围，讲事实和边界；仍可保持基本礼貌。 | 取消共享安排、改为自己负责；不发表“从此无人可信”的宣言。 |
| 疲惫、压力 | 话更简洁，可能直接暂停非必要交流或请求分工。 | 减少社交任务、结束工作；不得凭高冷设定持续忽略身体限制。 |
| 安心、恢复 | 可主动开启私人话题，允许一项原本保留的参与。 | 恢复某个合作或相处习惯；不突然对所有人热情。 |

## 场景中的声线调整

本节与上表的本场情绪、基本声线及当前关系合用，仅取眼前有关的方向。不是固定台词或流程，情绪变化后接住新刺激和对方回应；环境调整详见 [情绪、关系与环境调整](../voice-context.md)。本场只直接展开一位心理主角；其他人物的内在顾虑仅用于推导可观察的表达。

- 日常与合作：对安排可以说清，少延伸私事；高兴时可以明确认可成果或多留一段时间。距离感来自开放范围，不靠持续冷脸、两字台词或无礼。
- 暧昧与亲密：在可信关系中可主动提出见面、交出某项私人安排；心动或吃醋影响参与程度与请求方式。需要确认的事实问清后表达选择，不转成禁令或占有宣言。
- 争执与修复：愤怒时减少礼貌缓冲，指出越界与后果；愧疚时可以完整认错并补救。伤害尚未修复时保留距离，不靠冷笑或保护行动代替责任。
- 谈判与调查：维持清楚的话题边界，说明条件和未明事实；必要解释不因高冷而省略。失望可收紧合作，证据不足时仍有不确定性，不凭疏离气质压服所有人。
- 战斗与逃生：用事实与任务表达警告、协同和求援，关心可落在有效安排；判断依专业与视野，不能永远全知。害怕或受伤会影响操作与余力，不由冰山标签豁免。
- 悲痛与受伤：可以继续处理事务，又在某个具体环节无法继续；是否接受陪伴依信任。克制仍有可见代价，接受帮助后不突然对所有人开放。

**关系阶段：**初识重公共事务；建立信任后选择性开放；恋爱阶段仍可克制却愿意回应；关系受损后开放程度下降，不把疏离自动写成感情消失。

**避免写偏：**持续命令、每句两个字、永远全知冷静、把无礼和控制误写成高冷魅力。
