# 温柔体贴：人物声线与情绪表达

依据本书已确认的人物设定和当前阶段匹配后，读取本场相关情绪行及场景调整，同时保留基本声线、关系阶段与避免写偏说明。表中方向不要求全部出现，不能成为固定台词和动作。使用方法见 [声线总规则与索引](../character-voice.md)，环境、关系、强度和混合情绪见 [情绪、关系与环境调整](../voice-context.md)。

**适配依据：**人物主动留意他人的处境，帮助具体，尊重回应。温柔不要求顺从、压抑自己或无条件原谅。

**基本声线：**措辞照顾对象的接受方式，建议留有选择；可以直接提出需要和拒绝。关怀回应具体事情，不持续说安慰套话。

| 情绪或状态 | 对白与回应方式 | 行为、节奏与留白 |
| --- | --- | --- |
| 高兴 | 愿意分享好事，并回应对方参与的部分；自己的快乐可以明确说出。 | 留出共同体验的机会，不把所有好处都让出去。 |
| 期待 | 说清希望与安排，允许对方说明限制；体贴不能隐藏全部个人愿望。 | 做适量准备，也保留自己的时间，不为讨好过度包办。 |
| 害羞、心动 | 可表达欣赏、关心具体生活，亲密程度随关系增加。 | 为对方留一处方便，也允许自己的靠近被看见；不只有红脸低头。 |
| 失落、难过 | 可以温和说遗憾和需要，不必立即安慰造成失落的人。 | 暂时退出或请求陪伴，仍保留对自己的照顾。 |
| 委屈、受伤 | 指出哪里伤到了自己，要求回应；语气平和也能有力度。 | 停止一项不被尊重的帮助，不继续替对方收拾所有后果。 |
| 悲痛、重大失去 | 可能仍注意别人需要，但自己的表达和行动也会受限。 | 接受分担，允许某项事务暂时放下；不写成永远照顾所有人的工具。 |
| 愤怒 | 直接说清不能接受的行为与边界，不必大吼，也不立刻软化立场。 | 拒绝继续配合、结束越界交流；拒绝仍保持基本分寸。 |
| 吃醋 | 表达被忽略的感受或相处需要，不以体贴名义持续隐忍。 | 调整共同安排，给对方解释空间但不包揽解释。 |
| 害怕 | 能具体求助，必要时报告自己的限制；不强求先安抚别人。 | 接受照顾，保护能力范围内的人，不逞强忽略危险。 |
| 焦虑、不安 | 说明正在担心的实际问题，商量分工；答案明确后推进。 | 减少不必要任务、安排一次有效沟通，不反复关怀核对。 |
| 愧疚、后悔 | 承担属于自己的责任，提出补救，也能指出并非自己造成的部分。 | 修复实际损失，尊重对方暂不接受；不无限自责。 |
| 感动、接受安慰 | 认真回应帮助，让对方知道它有用；不急于马上回报。 | 接受陪伴或照顾，允许自己暂时成为被帮助的人。 |
| 失望、信任受损 | 语气可以仍温和，合作与私人开放程度会减少。 | 收回不再合适的付出，等待可验证的改变；不自动原谅。 |
| 疲惫、压力 | 清楚说出需要休息或分担，少做无意义解释。 | 把部分任务交出去，不靠继续包办证明温柔。 |
| 安心、恢复 | 更愿意表达自己的需要，也能自然关心他人。 | 恢复有余力的帮助，保留新建立的边界。 |

## 场景中的声线调整

本节与上表的本场情绪、基本声线及当前关系合用，仅取眼前有关的方向。不是固定台词或流程，情绪变化后接住新刺激和对方回应；环境调整详见 [情绪、关系与环境调整](../voice-context.md)。本场只直接展开一位心理主角；其他人物的内在顾虑仅用于推导可观察的表达。

- 日常与合作：注意具体需要，提出可选择的分工或帮助；高兴时也能表达自己的想做。温柔不等于每轮哄人、替别人决定或不断询问身体。
- 暧昧与亲密：邀请、靠近与照顾留给对方实际回应空间；期待和吃醋可以坦白自己的需要。善意不自动获得亲密许可，也不靠永远退让证明喜欢。
- 争执与修复：承认听到的具体问题，同时表达自己的界限；愤怒可清楚而直接，道歉与补救有实际范围。不充当全知心理咨询者，也不强迫双方当场和解。
- 谈判与调查：把受影响的人和现实成本纳入条件，必要时明确拒绝；询问顾及处境但仍核实事实。体贴不使人物放弃职责或相信所有说法。
- 战斗与逃生：先做能力范围内的有效协同，提醒或分担以现场需求为准；必要求援不遮掩。不能为照顾所有人无限透支，也不在危险中展开漫长安慰。
- 悲痛与受伤：陪伴方式依据对方真实回应，允许沉默、拒绝与有限帮助；自己悲痛时也可表达需要。沿用已知状态安排，不重复追问、不保证做不到的结果。

**关系阶段：**初识保持礼貌与距离；熟悉后照顾更具体；亲密关系中双方都应有需要与选择；受伤后温柔可以保留，信任和付出不必同时恢复。

**避免写偏：**无条件奉献、不断询问身体情况、永远理解伤害者、没有愤怒与底线。
