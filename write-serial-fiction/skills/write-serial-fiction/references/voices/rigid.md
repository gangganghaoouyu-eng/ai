# 执拗、偏执倾向：人物声线与情绪表达

依据本书已确认的人物设定和当前阶段匹配后，读取本场相关情绪行及场景调整，同时保留基本声线、关系阶段与避免写偏说明。表中方向不要求全部出现，不能成为固定台词和动作。使用方法见 [声线总规则与索引](../character-voice.md)，环境、关系、强度和混合情绪见 [情绪、关系与环境调整](../voice-context.md)。

**适配依据：**人物长期抓住某个目标、关系要求或解释，面对反证仍不容易调整。坚定、认真、执着追求与负面固执需看实际行为及代价。

**基本声线：**倾向把交流拉回自己最在意的一点，可能难以接受折中。核心执念应具体；人物在其他领域仍可以合理沟通，不必对一切都僵硬。

| 情绪或状态 | 对白与回应方式 | 行为、节奏与留白 |
| --- | --- | --- |
| 高兴 | 容易把结果看作自己坚持正确，愿意继续目标；也可正常分享。 | 加大原有投入，不能让作者默认所有坚持都正确。 |
| 期待 | 对某种结果有较强具体想象，可能较少准备替代方案。 | 坚持原计划，现实条件变化后应出现真实冲突。 |
| 害羞、心动 | 感情可能与既有目标混在一起，表达较认真，也可能难接受含糊。 | 投入集中但对方保留选择，不写成感情越强越有支配权。 |
| 失落、难过 | 可能不愿立刻改目标，围绕失败的关键原因说话。 | 继续尝试一次有新依据的办法，不反复做同一无效动作。 |
| 委屈、受伤 | 容易抓住一处未被承认的事实，但有效回答后要产生决定或新局面。 | 暂停合作、提出边界，不能无限要求对方重复解释。 |
| 悲痛、重大失去 | 可能难以接受失去，维持旧安排或寻找尚有依据的希望。 | 以具体行为呈现代价，阶段推进不能靠反复宣布不相信。 |
| 愤怒 | 更强调不可退让的一点，交流范围可能缩窄。 | 坚持某项行动、拒绝折中，现实后果与他人反应必须存在。 |
| 吃醋 | 可能难以接受关系与自己预期不同，要求表达具体位置。 | 对方已有效表态后，人物须面对选择，不循环索要相同保证。 |
| 害怕 | 更抓紧熟悉方法，也可能在现实迫使下首次改变。 | 沿用已有可靠步骤，旧办法无效时不无限重复。 |
| 焦虑、不安 | 想把事情拉回预设方向，问题围绕关键偏差。 | 做有限有意义的补救，不能为延长焦虑虚构不停出现的问题。 |
| 愧疚、后悔 | 承认错误可能艰难，但应明确错在哪里；不以坚持过久免责。 | 改变一项实际做法、承担坚持造成的损失。 |
| 感动、接受安慰 | 能被具体理解触动，可能愿意听一项不同意见。 | 暂停固有行动，给予新方案有限机会；不一次彻底通透。 |
| 失望、信任受损 | 可能固守旧判断，也可能因关键事实第一次松动。 | 关系处理取决于新证据，不能将怀疑机械扩展到所有人。 |
| 疲惫、压力 | 调整能力更弱，表达可能集中在核心要求；身体限制仍真实。 | 被迫停下、交出任务或继续承担代价，不能无限靠意志支撑。 |
| 安心、恢复 | 可以保持目标却放宽方法，或开始接受有限不确定。 | 成长体现为一项新选择，不要求放弃所有追求。 |

## 场景中的声线调整

本节与上表的本场情绪、基本声线及当前关系合用，仅取眼前有关的方向。不是固定台词或流程，情绪变化后接住新刺激和对方回应；环境调整详见 [情绪、关系与环境调整](../voice-context.md)。本场只直接展开一位心理主角；其他人物的内在顾虑仅用于推导可观察的表达。

- 日常与合作：围绕已有特定目标坚持安排或解释，其他事务未必固执；高兴时可能认可目标有进展。明确执拗的对象，不让每件小事都无法协商。
- 暧昧与亲密：可能抓紧既有承诺或某种关系理解，不安时难改解释；对方的界限与不同看法必须进入回应。不将持续纠缠自动写成深情，不复核已答清的关系问题。
- 争执与修复：可能回到特定旧依据，面对新事实依本书阶段决定是否松动；改变需有实际触发。不能让人物无信息变化地循环同一争执，也不靠一次说教完成转变。
- 谈判与调查：坚持某条底线或推断，关注信息可能偏向已有解释；错误判断应受现实后果约束。坚定与偏执分清，不凭执念证明其结论总是正确。
- 战斗与逃生：可能难于放弃原目标，撤退与继续之间的选择有实际代价；警告和协同仍要符合现场。不让执拗突破能力上限，或为停留争辩使时间停止。
- 悲痛与受伤：可能保留某项习惯、无法接受一项改变，或反复尝试尚未实现的任务；变化需刺激和经历支持。不把悲痛自动病理化，不以重复核对身体状态表达执念。

**关系阶段：**执拗可能只围绕某个创伤或目标；亲密关系不能代替本人承担改变；成长可从接受一种替代方案开始，不必瞬间彻底放下。

**避免写偏：**反复纠缠同一答复、任何事都偏执、坚持就必定得到奖励、他人只负责无限包容。
