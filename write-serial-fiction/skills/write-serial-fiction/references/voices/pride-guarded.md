# 傲娇、好面子：人物声线与情绪表达

依据本书已确认的人物设定和当前阶段匹配后，读取本场相关情绪行及场景调整，同时保留基本声线、关系阶段与避免写偏说明。表中方向不要求全部出现，不能成为固定台词和动作。使用方法见 [声线总规则与索引](../character-voice.md)，环境、关系、强度和混合情绪见 [情绪、关系与环境调整](../voice-context.md)。

**适配依据：**人物对显露在乎、接受帮助或承认需求有所顾虑，表达与行动之间存在可理解的分寸差。不能把伤害和无理取闹都归为傲娇。

**基本声线：**可能先说明事情本身，再留下个人需要；可以反驳或转移一点话题，但在关键处有真实回应。口是心非不能成为每场固定程序。

| 情绪或状态 | 对白与回应方式 | 行为、节奏与留白 |
| --- | --- | --- |
| 高兴 | 对好事有具体兴趣，可能对夸奖保持一点分寸；无需马上否认高兴。 | 保留收到的东西、主动继续共同活动；不固定使用嫌弃之后偷偷收藏。 |
| 期待 | 以安排或准备切入，希望得到回应；可找理由提出同行，也可直接邀请。 | 提前准备却不过分说明动机；不能一直等对方读懂暗示。 |
| 害羞、心动 | 可能改口、谈眼前小事缓冲，也能在特定时点承认。 | 调整距离、将递出的东西留下；动作有现场缘由，不机械别过脸。 |
| 失落、难过 | 可能先表现得不愿多谈，随后指出具体落空的期待。 | 暂时收起准备物、减少回应；不给每次失落安排逞强台词。 |
| 委屈、受伤 | 更在意对方是否理解自己的用心，可能先较硬地指出事实。 | 停止额外付出，但保留必要合作；不能仅用发脾气替代说明。 |
| 悲痛、重大失去 | 好面子可能暂时无法维持，或只在外人面前维持；表达可失去平常锋芒。 | 处理熟悉物件时停下、接受一项陪伴；不在严重失去中硬塞嘴硬笑点。 |
| 愤怒 | 措辞容易尖锐，应该围绕具体越界；误伤他人要有后果。 | 退开、结束事务或明确拒绝；不把辱骂写成可爱的亲密。 |
| 吃醋 | 可以借安排问清位置、说出被忽略的需要；不能一直否认后又追问。 | 改变参与方式，决定留下或离开；亲密权利受当前关系限制。 |
| 害怕 | 可能先说自己还能做什么，再接受帮助；危急时可以直接求助。 | 抓住可用支撑、跟随行动；不靠逞强拖延危险处理。 |
| 焦虑、不安 | 想保持从容，可能更关注准备是否齐全；问题有答案后转向实际行动。 | 多做一项准备，必要时把事情交出去；不重复要求保证。 |
| 愧疚、后悔 | 道歉可能有组织过程，但应具体承担错误；不能只拿东西堵住问题。 | 先补救再开口，或边处理边说明；对方可以不马上原谅。 |
| 感动、接受安慰 | 可以用较短感谢、实际回馈或坦白一部分感受回应。 | 不再拒绝帮助，允许对方留下；无需每次先说“不需要”。 |
| 失望、信任受损 | 难以继续维持以前的逗趣，会更直接划清哪些事不能接受。 | 收回原本的偏爱或习惯；修复需要行动，不靠一次追哄。 |
| 疲惫、压力 | 修饰和掩饰减少，可能直接说累或需要休息。 | 不再费力维护表现，接受分担；不能把疲惫全部写成暴躁。 |
| 安心、恢复 | 对需要的表达更自然，能接受玩笑并回应；仍可保留分寸。 | 主动恢复共同安排，少一点防备性转移；不强制变成坦率外向。 |

## 场景中的声线调整

本节与上表的本场情绪、基本声线及当前关系合用，仅取眼前有关的方向。不是固定台词或流程，情绪变化后接住新刺激和对方回应；环境调整详见 [情绪、关系与环境调整](../voice-context.md)。本场只直接展开一位心理主角；其他人物的内在顾虑仅用于推导可观察的表达。

- 日常与合作：可以借事务提出参与，口头保留与实际帮助相互呼应；高兴时是否承认依熟悉程度。好面子不等于每轮都否认、挖苦或把感谢改成辱骂。
- 暧昧与亲密：期待或吃醋可先从原有安排切入，给自己和对方留余地；私下有信任时也能承认在意。被回应后要有实际变化，不无限嘴硬再反复审问。
- 争执与修复：公共场合可能更顾及体面，私下可说出真正越界之处；认错需要跨过面子，但仍承认具体责任。不能把攻击性的言语当作无需回应的可爱表现。
- 谈判与调查：可借充分准备维护体面，对条件有自己的立场；被质疑时愤怒也受筹码限制。资料不足就继续核实，不为不肯服输编造确定答案。
- 战斗与逃生：必要求助、提醒与协同直接说，不为了面子拒绝有效救援；关心落在任务和行动上。短句可以仍有本人措辞，但不在危险中长篇争辩谁更在乎。
- 悲痛与受伤：可以不愿公开示弱，向可信对象提出具体陪伴或帮忙；接受之后不立即反话否认。强烈伤痛不强加打闹或假装毫不在意。

**关系阶段：**初识顾及体面；熟悉后分寸差可成为互动趣味；稳定关系里允许越来越直接；受伤后先判断问题性质，不能继续把真实矛盾写成打情骂俏。

**避免写偏：**每句“谁在乎你”、长期否认事实、伤害别人后无需负责、对方永远负责猜和哄。
