# 内向安静：人物声线与情绪表达

依据本书已确认的人物设定和当前阶段匹配后，读取本场相关情绪行及场景调整，同时保留基本声线、关系阶段与避免写偏说明。表中方向不要求全部出现，不能成为固定台词和动作。使用方法见 [声线总规则与索引](../character-voice.md)，环境、关系、强度和混合情绪见 [情绪、关系与环境调整](../voice-context.md)。

**适配依据：**偏好有限而深入的交流、需要组织表达的时间、对公开表达较克制。不能仅凭冷淡或自卑判断内向。

**基本声线：**开口有目的，措辞可以完整、准确，熟悉后也可能健谈。不必持续省略、结巴或低声说话；不愿参与与没有能力表达分别处理。

| 情绪或状态 | 对白与回应方式 | 行为、节奏与留白 |
| --- | --- | --- |
| 高兴 | 可以具体肯定一件事，或主动说出一个平时不提的细节；不要求大声表达。 | 多停留一会儿、主动递来资料或参与约定；愉悦也可通过增加参与体现。 |
| 期待 | 问清与准备有关的必要事项，可能把愿望说得较短但明确。 | 预留时间、做好准备；不把期待写成反复试探对方会不会记得。 |
| 害羞、心动 | 回应可能比平时更谨慎，先说事实再承认感受；可信关系中也能直接表达。 | 愿意留在对方身边却少开新话题，手里的事短暂中断；避免固定低头绞衣角。 |
| 失落、难过 | 减少无关交流，可能直接说想独处；对具体帮助仍能回应。 | 退出热闹场合、继续一项熟悉事务；独处不等于拒绝所有人。 |
| 委屈、受伤 | 可能先听完对方，再指出最重要的一处误解；压抑达到限度时可完整说清。 | 暂停原本合作的动作，保持距离；沉默之后要有真实未说出的理由。 |
| 悲痛、重大失去 | 更难组织私人感受，可能先处理必要事务；真正表达时可以很具体。 | 维持一小段固定作息或反复触及有依据的旧物；不给每个动作解释悲痛意义。 |
| 愤怒 | 表达可能变得少而直接，清楚指出边界；不必通过吼叫证明愤怒。 | 结束谈话、收回交付物或停止配合；也可选择留下完成说明。 |
| 吃醋 | 倾向选私下时机谈具体疑问或需要；不必一味退出和放弃。 | 减少参与，随后决定是否开口；不能以性格为由让关键交流永远不发生。 |
| 害怕 | 可以简短求助、报告事实，少解释自己的感受。 | 跟随明确安排、接近熟悉出口；身体反应来自具体危险。 |
| 焦虑、不安 | 先在已有信息中组织问题，可能只问最关键的一项；必要时明确请求时间。 | 将待办集中处理、避开额外社交；不写成无尽内耗独白。 |
| 愧疚、后悔 | 可以准备好后认真道歉，说明行为和补救；表达慢不等于逃避责任。 | 把具体损失补上，等待对方回应；不让补偿代替必须说清的事。 |
| 感动、接受安慰 | 感谢可能简短，但会对帮助本身具体回应；亲近后可说更多。 | 接受陪伴、主动留下对方或分享一项私事；不以无限沉默代替接纳。 |
| 失望、信任受损 | 更明确限制交流范围，私事减少；必要的合作可以继续。 | 更少主动邀请，收回某些共享安排；修复不能凭一次长谈完成。 |
| 疲惫、压力 | 更需要安静，直接交代最低限度事项；无力解释时可以清楚提出暂停。 | 减少外部刺激、安排独处时间；不将寡言写成对同伴的持续冷暴力。 |
| 安心、恢复 | 自主开口的次数或内容增加，愿意讨论下一步；无须变成外向人。 | 回到熟悉事务，重新接受少量社交；恢复保留原有表达节奏。 |

## 场景中的声线调整

本节与上表的本场情绪、基本声线及当前关系合用，仅取眼前有关的方向。不是固定台词或流程，情绪变化后接住新刺激和对方回应；环境调整详见 [情绪、关系与环境调整](../voice-context.md)。本场只直接展开一位心理主角；其他人物的内在顾虑仅用于推导可观察的表达。

- 日常与合作：从手头事项进入话题，必要建议可以完整说；高兴时向合适对象分享具体细节，疲惫时减少闲聊。安静不等于不会协商或总靠别人猜。
- 暧昧与亲密：在有信任的空间提出小而明确的邀请，心动可以表现在愿意延长相处；不安时表达一个实际顾虑。是否主动由经历决定，不永远等对方追问。
- 争执与修复：公共场合可能先给短而清楚的界限，私下有余力时再说明原因；愤怒也可直接拒绝。道歉和接受修复依具体行为，不把每次沉默写成同意。
- 谈判与调查：可先听取信息再提出重点问题，必要条件不因话少而省略；证据不足时说明未明之处。紧张影响时机和措辞，不使人物失去判断或总被抢走决定权。
- 战斗与逃生：直接报告位置、障碍、自己的限制或求援，必要时提高音量；不为保持内向拖欠警告。选择路线和配合方式依据实际能力，非必要谈话可以延后。
- 悲痛与受伤：可以提出独处、接受安静陪伴或把一项事务交出去；可信对象面前也可能说较多。是否开口随刺激与信任改变，不由旁白代写其全部心事。

**关系阶段：**陌生场合更节制；信任的人面前可有完整情绪和趣味；冲突后可能暂时恢复距离；长期成长可以更敢提出需要，但不强制改变内向基础。

**避免写偏：**永远“嗯”“好”、逢事怯懦、毫无主见、说一句话就三次停顿。
