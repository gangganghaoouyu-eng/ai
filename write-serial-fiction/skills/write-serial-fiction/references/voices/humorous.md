# 幽默、善于调节气氛：人物声线与情绪表达

依据本书已确认的人物设定和当前阶段匹配后，读取本场相关情绪行及场景调整，同时保留基本声线、关系阶段与避免写偏说明。表中方向不要求全部出现，不能成为固定台词和动作。使用方法见 [声线总规则与索引](../character-voice.md)，环境、关系、强度和混合情绪见 [情绪、关系与环境调整](../voice-context.md)。

**适配依据：**人物能够留意现场的有趣差异，擅长通过轻松表达建立交流。幽默可以温和、干涩、机敏或夸张，具体形式由本书经历决定。

**基本声线：**笑点来自当下细节和关系，回应仍有实质内容。玩笑有对象、分寸和停止时机，不连续抛网络梗，不让所有句子都承担搞笑任务。

| 情绪或状态 | 对白与回应方式 | 行为、节奏与留白 |
| --- | --- | --- |
| 高兴 | 愿意分享有趣发现或给共同经历添一句轻松回应，随后正常交流。 | 借现成物件或任务制造一点趣味；不需要每轮加笑点。 |
| 期待 | 可轻松描述自己的准备或愿望，让对方容易接话；关键安排仍说清楚。 | 提前做准备，留一个与关系相符的小惊喜；不以玩笑掩盖所有认真。 |
| 害羞、心动 | 可以借玩笑缓冲亲近，也可能在关键一句停下幽默，认真回应。 | 平时流畅的接话短暂变慢，行为仍贴着事务；不固定自嘲贬低自己。 |
| 失落、难过 | 玩笑可能减少，也可能用一次轻松表达保住体面；对方回应后进入真实话题。 | 收起原本逗趣的安排，选择继续或暂停活动；不能永远用哈哈带过难过。 |
| 委屈、受伤 | 可能先轻描淡写，发现未被理解后直接说明伤处。 | 停止替对方圆场，明确不再参与某类玩笑；认真时让对方听见变化。 |
| 悲痛、重大失去 | 可以完全不幽默；极少量旧习惯若出现，应有具体触发与分量。 | 保留任务中的真实阻滞和陪伴，避免严重失去现场强行段子。 |
| 愤怒 | 平时轻松的表达可能收起，或出现有针对性的讽刺；尖刻要有后果。 | 不再调节气氛，直接要求处理问题；不能靠“开玩笑”撤销冒犯。 |
| 吃醋 | 一次玩笑可以试探，但要根据回应转向具体需要或停止追问。 | 参与方式改变，不继续为让自己在意的场面助兴；避免无限阴阳怪气。 |
| 害怕 | 在允许的安全空间里可能用轻松一句稳住同伴，随后给明确信息。 | 行动优先，不在即时危险中演喜剧；严重恐惧可打乱机智。 |
| 焦虑、不安 | 可能先用轻松方式问关键事项，再选择具体办法；不能用笑点反复套答案。 | 做准备、分配任务，也可能暂时失去组织笑点的余力。 |
| 愧疚、后悔 | 道歉应认真、具体；若有缓冲玩笑，也不能稀释责任。 | 做实际补救，接纳对方不愿接梗；不以自嘲迫使别人安慰。 |
| 感动、接受安慰 | 可先用熟悉语气接住，随后给一个明确感谢或认真回应。 | 接受帮助，选择让对方看到真实需要；不每次都说笑来躲开。 |
| 失望、信任受损 | 笑点和亲近称呼可能减少，普通礼貌仍在；私下界限应清楚。 | 停止帮对方缓和局面，取消默认同行；不把失望只写成更会讽刺。 |
| 疲惫、压力 | 幽默能力或意愿下降，表达更平实；无需强迫其继续活跃场面。 | 坐下、结束事务、请求分担；仍可保留偶尔自然的趣味。 |
| 安心、恢复 | 玩笑重新出现，分量适中，对认真话题仍能切换。 | 重新参与共同活动，恢复熟悉互动；不凭一个笑话判定创伤结束。 |

## 从不同理解和关注点组织幽默

幽默可以来自人物对眼前规则、利益、任务或关系的不同理解，也可以来自他们关注的细节不同。让笑点落在实际回答、具体选择及其后果上，再接对方真实的回应与调整。利用已有的语境与信息差，不为制造笑点临时安排无依据的误会或让人物失去判断力。

可以用于对白，也可以用于本场心理主角符合人设的内心吐槽；心理的口语分量按本人经历、状态与时代选择，采用 [视角、心理与留白](../perspective-restraint.md)。同场其他人物通过实际反应参与，不直接揭晓其内心，也不要求所有人一起接梗。

不靠重复反应词代替回应，不要求每轮都有包袱；即时危险优先处理行动，玩笑受人物余力和现实后果约束。悲痛与严重压力下允许人物完全不幽默。笑点之后继续眼前事务，不重复解释已经通过反应呈现的笑点，也不替读者总结笑话体现了什么关系意义。

## 场景中的声线调整

本节与上表的本场情绪、基本声线及当前关系合用，仅取眼前有关的方向。不是固定台词或流程，情绪变化后接住新刺激和对方回应；环境调整详见 [情绪、关系与环境调整](../voice-context.md)。本场只直接展开一位心理主角；其他人物的内在顾虑仅用于推导可观察的表达。

- 日常与合作：从现场细节与共同经历组织轻松话题，高兴时邀请对方接话；玩笑之后回到实际事务。对方不接或表现不适时调整，不每句都安排包袱。
- 暧昧与亲密：玩笑可以试探邀请，但关键请求要让对方听懂；心动时也可能暂时接不上笑话。吃醋不借嘲弄第三人或持续打趣回避真实需要。
- 争执与修复：轻微分歧可缓和，明确伤害出现后停止拿它取笑；愤怒时可以直接划界。道歉说清责任，不把笑话当作对方必须原谅的理由。
- 谈判与调查：幽默可用于探路或缓和僵局，实际条件、事实和疑点仍需明确；根据对方身份选择分寸。不以机智回嘴替代核实，也不让所有人必然被说服。
- 战斗与逃生：先完成警告、求助与协同，确有余地且符合经历时才有极少轻松回应。恐惧可以使幽默消失，不为展示性格拖慢行动或拿他人危险开玩笑。
- 悲痛与受伤：可以完全不再玩笑，或在合适关系和时机接住对方主动给出的轻松话题；不强行治愈气氛。真实担忧和已知身体情况用实际照顾继续。

**关系阶段：**陌生人前注意边界；熟人有共同经历可调侃；亲密关系可以互相接梗；信任受损时共同笑点未必还能使用。

**避免写偏：**处处抖机灵、借幽默冒犯弱者、玩笑代替道歉、悲伤场景仍负责逗乐所有人。
