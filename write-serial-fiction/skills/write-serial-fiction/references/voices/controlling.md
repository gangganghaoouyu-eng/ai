# 控制欲强：人物声线与情绪表达

依据本书已确认的人物设定和当前阶段匹配后，读取本场相关情绪行及场景调整，同时保留基本声线、关系阶段与避免写偏说明。表中方向不要求全部出现，不能成为固定台词和动作。使用方法见 [声线总规则与索引](../character-voice.md)，环境、关系、强度和混合情绪见 [情绪、关系与环境调整](../voice-context.md)。

**适配依据：**人物习惯替别人决定安排、限制选择或要求按自己的方式行动。普通领导分工和一次危险中的命令不足以认定该倾向。

**基本声线：**容易使用要求、安排和附带条件的表达，可能将关心与干预混在一起。是否意识到越界、是否改变由本书阶段决定；他人的拒绝和后果需要真实存在。

| 情绪或状态 | 对白与回应方式 | 行为、节奏与留白 |
| --- | --- | --- |
| 高兴 | 可能迅速安排庆祝，认为大家会配合；也可向在意的人展示成果。 | 先做安排再听反馈，若越界需留下对方的实际反应。 |
| 期待 | 希望按自己设想进行，可能将愿望说成计划或要求。 | 预设时间与人员，不自动让所有人接受。 |
| 害羞、心动 | 可能借实际安排维持主动位置，也可因无法掌握回应而迟疑。 | 增加照顾或介入，双方是否接受要在场景中呈现。 |
| 失落、难过 | 容易想改变安排、追究哪里失控；也可能暂时撤回交流。 | 重新分配资源，但不能凭情绪获得不存在的权力。 |
| 委屈、受伤 | 可能把未被配合理解成不被重视，要求说明；判断可以有偏差。 | 停止帮助或增加条件，行为不由旁白判为合理。 |
| 悲痛、重大失去 | 可能抓紧剩下可控制的事务，也可能因无能为力失去惯常条理。 | 反复行为若确需呈现，简洁说明其影响，不写成重复确认对白。 |
| 愤怒 | 更容易下要求、限定后果，冲突围绕对方选择展开。 | 干预安排或撤回资源，必须受到现实边界和他人行动制约。 |
| 吃醋 | 容易要求优先位置或限制交往；若本书写此行为，要呈现越界与冲突。 | 不把占有命令自动当作甜蜜，不允许亲密动作略过对方拒绝。 |
| 害怕 | 试图掌握步骤与人员，可能更急于统一行动。 | 若行动有效有现实理由；若妨碍脱险须承担后果。 |
| 焦虑、不安 | 可能加紧安排、减少他人自由裁量；重点写新要求带来的局势变化。 | 已知情况不重问，不以不断核对身体状态包装控制。 |
| 愧疚、后悔 | 可以承认越界，也可能只解释动机；是否真正认错由行为辨别。 | 真正改善体现为撤回不当要求、接受拒绝，而非保证以后更好地控制。 |
| 感动、接受安慰 | 可能第一次允许事情不由自己安排，或仅接受有限帮助。 | 交出一项决定权，若只是短暂改变不宣告性格已治愈。 |
| 失望、信任受损 | 可能提高控制要求，也可能终止关系；要符合实际条件。 | 对方保留离开、反驳和寻求支持的能力。 |
| 疲惫、压力 | 更难容忍变化，措辞可能急促；也可能被迫交出事务。 | 控制能力受体力和资源限制，不能永远支配全局。 |
| 安心、恢复 | 可以减少一项干预，听取他人安排；未成长者也可能恢复原习惯。 | 具体变化与阶段对应，不由一次放手推定完全改变。 |

## 场景中的声线调整

本节与上表的本场情绪、基本声线及当前关系合用，仅取眼前有关的方向。不是固定台词或流程，情绪变化后接住新刺激和对方回应；环境调整详见 [情绪、关系与环境调整](../voice-context.md)。本场只直接展开一位心理主角；其他人物的内在顾虑仅用于推导可观察的表达。

- 日常与合作：有设定依据时，干预可表现为抢先安排、替人决定或限制选择；对方反应应有实际后果。正常分工与越界控制分清，不把一切关心都写成控制。
- 暧昧与亲密：在意与不安可能引出超出关系权限的要求，但要让越界及回应可见；修复阶段减少干预需有经历支持。不把禁令、占有或替人同意写成普遍深情。
- 争执与修复：愤怒时可能争夺决定权、规定对方回应；若本书安排成长，需具体撤回越界要求并接受对方选择。不能一句认错便自动完成改变。
- 谈判与调查：可能试图决定议程、限定选项或获取有利信息；成效受身份、筹码和对方判断限制。不能凭人格让所有人服从，不把职责内要求等同控制倾向。
- 战斗与逃生：区分有效指挥与越权干预，命令受实际岗位、能力和现场证据约束；恐惧可以使干预加重，但要写真实影响。不能为了展示强势牺牲协同因果。
- 悲痛与受伤：可能想通过安排事务降低不安，也可能对失控难以适应；照顾中的选择权与对方反应仍保留。不重复核对已明确状态，不把强制照顾自动写成治愈。

**关系阶段：**控制可能对不同对象程度不同；亲密不自动赋予干预权；修复阶段若出现成长，要落实到允许选择和接受拒绝。

**避免写偏：**把控制直接写成深情、他人毫无选择、一句道歉取消长期伤害、无限掌权。
