# 多疑、防备：人物声线与情绪表达

依据本书已确认的人物设定和当前阶段匹配后，读取本场相关情绪行及场景调整，同时保留基本声线、关系阶段与避免写偏说明。表中方向不要求全部出现，不能成为固定台词和动作。使用方法见 [声线总规则与索引](../character-voice.md)，环境、关系、强度和混合情绪见 [情绪、关系与环境调整](../voice-context.md)。

**适配依据：**已有经历和行为显示人物对信息来源与他人动机难以信任。不得因一次谨慎直接套入；谨慎可仅限某类事务。

**基本声线：**保留私人信息，问依据、条件和责任，对回答的确信程度有限。但有效答复会进入下一步判断，不能无限盘问。

| 情绪或状态 | 对白与回应方式 | 行为、节奏与留白 |
| --- | --- | --- |
| 高兴 | 可承认好结果，同时保留尚未公开的部分；喜悦无需完全消失。 | 接受收益但不立即交出全部权限，不逐项重查已证实结果。 |
| 期待 | 想参与，却先问关键条件或边界；条件明确后决定。 | 做自己能掌控的准备，保留必要退出安排，不无限设想背叛。 |
| 害羞、心动 | 愿意靠近又保留判断，可能先谈具体安排和自己的限制。 | 少量开放信息，观察实际后续；不无证据测试对方忠诚。 |
| 失落、难过 | 可能先怀疑结果是否被人为改变，但须有依据才提出。 | 收紧某项投入、整理真正相关的新信息，不能凭失落发明阴谋。 |
| 委屈、受伤 | 想弄清对方知道什么、做过什么，随后表达受损之处。 | 暂停合作或共享，不让同一事实被多轮重复核对。 |
| 悲痛、重大失去 | 防备可能加强，也可能因失去可信者而难以选择援助。 | 从有限可靠帮助开始，不能自动认为所有人都有恶意。 |
| 愤怒 | 针对明确矛盾追问责任，语气可能强硬；不把推测说成事实。 | 收回权限、要求解释新增疑点，行动受证据与身份限制。 |
| 吃醋 | 容易注意不一致的说法，但有效解释后应处理自己的不安或边界。 | 决定暂停接近或谈清安排，不连续搜查、核问来表现感情。 |
| 害怕 | 优先问来源与可信度，寻找有根据的安全选择。 | 依靠既有可靠渠道，不因多疑放弃所有可用援助。 |
| 焦虑、不安 | 想补足未知信息，问题限定于真正影响决定的缺口。 | 取得有效依据后选择行动；不得为继续焦虑制造新疑点。 |
| 愧疚、后悔 | 面对自己误判可以承认事实，是否完整道歉符合既有阶段。 | 撤回不当限制、修补损害，不立即恢复对所有人的信任。 |
| 感动、接受安慰 | 善意可逐步使其减少一项保留，也可能只接受明确帮助。 | 允许对方参与有限事务，接纳通过实际行为累积。 |
| 失望、信任受损 | 对已经证实的失约作出限制，可能更难再次开放。 | 依据具体事实减少托付，不重新把所有旧事逐件盘问一遍。 |
| 疲惫、压力 | 判断更难维持，可能选择少数可靠事项或暂时退出。 | 缩减信息处理，不被写成疲惫时仍洞察全部阴谋。 |
| 安心、恢复 | 愿意把某件事交出去，表达中的保留减少。 | 不再主动重做已完成的确认，允许不确定性存在。 |

## 场景中的声线调整

本节与上表的本场情绪、基本声线及当前关系合用，仅取眼前有关的方向。不是固定台词或流程，情绪变化后接住新刺激和对方回应；环境调整详见 [情绪、关系与环境调整](../voice-context.md)。本场只直接展开一位心理主角；其他人物的内在顾虑仅用于推导可观察的表达。

- 日常与合作：依已有信任困难保留信息和安排，合作范围可以明确；安心后逐步放开一项事务。不能把普通谨慎升级成处处审讯或反复核对有效答案。
- 暧昧与亲密：想靠近与防备可以并存，具体顾虑有既有经历或新信息依据；对回应给有限但真实的接纳。不用吃醋持续审查忠诚，也不把沉默默认成背叛。
- 争执与修复：说清哪些已发生的行为使合作受限，补救需要实际兑现；新证据可改变一部分判断。不能无变化地反复索要保证，也不由旁白确认所有疑心都对。
- 谈判与调查：关注信息来源、可验证条件与风险承担，仅追问新增或未明部分；有效证据出现后更新判断。怀疑可以错，不能凭多疑直接识破全部谎言。
- 战斗与逃生：可保留必要防范或先确认未明的协同条件，急迫时根据可用事实选择；不能因防备无限拖延有效逃生。新问题没有出现时不重问位置、伤势和已有命令。
- 悲痛与受伤：是否接受帮助依提供者、可行条件及信任，允许有限托付；旧伤不会因安慰立即消失。不能把关心都自动写成阴谋，或让人物拒绝每次实际帮助。

**关系阶段：**初识问必要条件；信任通过具体经历积累；旧背叛可能影响特定事务；关系修复要有可见行为，不让新关系自动承担全部过去。

**避免写偏：**重复盘问、无证据指控、永远猜中、把侵入隐私写成理所当然。
