# 敏感细腻：人物声线与情绪表达

依据本书已确认的人物设定和当前阶段匹配后，读取本场相关情绪行及场景调整，同时保留基本声线、关系阶段与避免写偏说明。表中方向不要求全部出现，不能成为固定台词和动作。使用方法见 [声线总规则与索引](../character-voice.md)，环境、关系、强度和混合情绪见 [情绪、关系与环境调整](../voice-context.md)。

**适配依据：**人物能注意到措辞、互动习惯、环境和关系分寸的细微变化。敏感不等于自卑、多疑或准确读心。

**基本声线：**回应具体细节，可能先考虑对方的接受方式；可以清楚表达自己的发现与需要。观察有事实来源，推测保留不确定。

| 情绪或状态 | 对白与回应方式 | 行为、节奏与留白 |
| --- | --- | --- |
| 高兴 | 记得并说出让自己受重视的具体细节，也可分享感官体验。 | 保存一项有分量的安排，回应对方真正做过的事。 |
| 期待 | 希望有具体互动，可能对约定的小部分格外在意。 | 做贴合对方习惯的准备，不把每个细节都渲染成重大意义。 |
| 害羞、心动 | 对称呼、距离或特别照顾有反应，表达可含蓄也可直接。 | 调整参与方式，保留一处原本会略过的动作；不替对方确定爱意。 |
| 失落、难过 | 可以指出期待与实际之间的差别，不必解释所有细微感受。 | 收起某项准备，减少一个熟悉互动；不长篇复盘每句话。 |
| 委屈、受伤 | 更在意被忽略、误解或轻描淡写，表达应指向具体事件。 | 暂停分享或合作，把真正需要对方回应的部分说清。 |
| 悲痛、重大失去 | 某个习惯或细节可能触发难以承受的感受，但触发需有旧事依据。 | 在日常空缺中表现失去，不连续堆叠悲伤物件和回忆。 |
| 愤怒 | 可能因对方忽视边界而变得明确、锋利；不只通过流泪表现。 | 停止顾及对方体面，拒绝继续让步；仍受当前关系约束。 |
| 吃醋 | 注意互动差异，但要把发现与猜测分开，必要时表达自己的需要。 | 不再主动参与某个场面，选择一次有效沟通；不无限解释微表情。 |
| 害怕 | 容易注意异常声音或环境差异，报告实际发现而非神秘直觉。 | 寻找可依靠的信息与位置；不能自动先于所有人预知危险。 |
| 焦虑、不安 | 可能对不明确回应较在意，针对关键遗漏询问一次。 | 调整准备、选择等待或行动；已有效答复的内容不再循环。 |
| 愧疚、后悔 | 能注意自己行为造成的具体影响，说明实际责任。 | 补正被忽略的需要，不揽下别人所有情绪。 |
| 感动、接受安慰 | 对贴合需要的帮助反应较深，可说清其中一处缘由。 | 允许进一步陪伴，保留没准备说出的部分，不替读者总结。 |
| 失望、信任受损 | 对旧习惯的变化有意识，愿意减少依赖或明确问题。 | 不再默认某项共享安排，修复取决于行动而非解释细节。 |
| 疲惫、压力 | 对额外交流和环境刺激更难承受，直接提出安静或暂停。 | 缩减事务和注意范围，不让人物每时每刻都观察一切。 |
| 安心、恢复 | 可以重新注意轻松细节，减少防备性解释。 | 愿意接受未完全可控的相处，恢复某个熟悉习惯。 |

## 场景中的声线调整

本节与上表的本场情绪、基本声线及当前关系合用，仅取眼前有关的方向。不是固定台词或流程，情绪变化后接住新刺激和对方回应；环境调整详见 [情绪、关系与环境调整](../voice-context.md)。本场只直接展开一位心理主角；其他人物的内在顾虑仅用于推导可观察的表达。

- 日常与合作：能注意称呼、参与和习惯的变化，依据实际内容回应；高兴时可珍惜具体细节。注意到差异不等于每次都负面解读或要求确认。
- 暧昧与亲密：对邀请、距离和回应的分量可能更留意，期待与不安可以并存；有疑点问清具体事项后继续。不能仅凭一次动作确认对方心意，也不不断求保证。
- 争执与修复：把自己被哪一句话或哪项行为触动说具体，允许对方提供不同理解；修复回应实际改变。感受强烈不使其推断天然正确，也不反复翻译同一受伤。
- 谈判与调查：注意现场互动与细节差异，可提出核实问题；事实与自身感觉分开。敏感不授予读心、测谎或凭气氛找出真相的能力。
- 战斗与逃生：注意到的信息只在当前视野与余力内，报告具体异常并参与协同；害怕可以压缩表达。不能为描写细腻停住行动、感知全部战场或忽略体力。
- 悲痛与受伤：具体旧习惯、物件与缺席可成为触发点，回应随强度与信任改变；不必每轮哭泣。接受帮助后允许有限缓和，不不断重新描述同一种痛苦。

**关系阶段：**初识的观察保持距离；熟悉后细节来自共同经历；信任破裂后不把所有旧温柔判成虚假；成长可提高表达需要的能力。

**避免写偏：**全知读心、每句话过度分析、逢事哭泣、准确识破所有隐藏动机。
