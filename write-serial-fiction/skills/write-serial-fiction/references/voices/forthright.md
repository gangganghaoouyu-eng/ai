# 直率果断：人物声线与情绪表达

依据本书已确认的人物设定和当前阶段匹配后，读取本场相关情绪行及场景调整，同时保留基本声线、关系阶段与避免写偏说明。表中方向不要求全部出现，不能成为固定台词和动作。使用方法见 [声线总规则与索引](../character-voice.md)，环境、关系、强度和混合情绪见 [情绪、关系与环境调整](../voice-context.md)。

**适配依据：**人物愿意清楚表达立场，面对选择能较快行动。直率不要求缺少思考，果断不保证判断正确。

**基本声线：**倾向明确的陈述、请求和方案，理由按需要给足；能听取新信息并修正。措辞强度符合关系，不以命令所有人显示果断。

| 情绪或状态 | 对白与回应方式 | 行为、节奏与留白 |
| --- | --- | --- |
| 高兴 | 直接说喜欢、满意或愿意参加，认可具体成果。 | 主动推动共同活动，不替所有人决定怎样庆祝。 |
| 期待 | 清楚提出邀请或目标，确认必要条件后准备。 | 留时间、着手安排，不不断催对方表态。 |
| 害羞、心动 | 可以直接表达，也可能在私事上比平时慢；两种都需人设支持。 | 提出具体同行或见面，给对方真实拒绝空间。 |
| 失落、难过 | 承认落空之处，可能较快谈下一步，但不必马上想通。 | 调整计划或暂停行动，不用解决方案覆盖全部情绪。 |
| 委屈、受伤 | 指出误解与损害，说明需要怎样处理。 | 停止不公平安排，要求补正；不靠不断追问争一个答案。 |
| 悲痛、重大失去 | 可以处理必要事务，也可能对无法改变的事失去方向。 | 做能做的事，允许求助和停下；果断不能使悲痛消失。 |
| 愤怒 | 直接说问题、要求与后果，必要时拒绝继续谈。 | 采取与边界相符的行动，不用打砸证明强硬。 |
| 吃醋 | 可以清楚说自己在意什么，也承认对方的选择权。 | 约定下一步交流或改变自己的参与，不自动掌控对方社交。 |
| 害怕 | 报告危险、提出援助或行动顺序，情绪可以同时存在。 | 快速采取可行措施，行动受能力与信息限制。 |
| 焦虑、不安 | 聚焦最影响决定的问题，获得答案后承担选择。 | 拆分任务、选定方案；不能无证据不断否决再确认。 |
| 愧疚、后悔 | 明确认错和补救，不将直率当成伤人的免责理由。 | 改正行动，接受实际后果，不要求对方立即翻篇。 |
| 感动、接受安慰 | 可直接道谢、说出帮助解决了什么，提出真实需要。 | 接受分担，主动回应陪伴；不必用更强大的形象遮掩。 |
| 失望、信任受损 | 明确减少哪些合作或亲近，提出恢复需要的条件。 | 执行边界，条件应可理解，不以惩罚代替沟通。 |
| 疲惫、压力 | 直接交代能做与不能做的部分，可能减少修饰。 | 暂停、交接或请求支援，不强行独自完成全部任务。 |
| 安心、恢复 | 能讨论新的安排，重新承担适合的事务。 | 行动能力逐步恢复，保留从经历中学到的限制。 |

## 场景中的声线调整

本节与上表的本场情绪、基本声线及当前关系合用，仅取眼前有关的方向。不是固定台词或流程，情绪变化后接住新刺激和对方回应；环境调整详见 [情绪、关系与环境调整](../voice-context.md)。本场只直接展开一位心理主角；其他人物的内在顾虑仅用于推导可观察的表达。

- 日常与合作：直接提出安排、需要和选择，高兴时明确认可；不愿参与时给清楚回应。直率仍有礼貌与信息分寸，不把所有小事都变成命令。
- 暧昧与亲密：可直接邀请或承认期待，害羞也可能暂时找不到合适词；吃醋表达自己的感受与请求。坦率不默认关系权利，更不替对方作同意决定。
- 争执与修复：指出具体行为、影响和希望改变的部分；认错可以简洁清楚，后接补救。愤怒不必喊叫，解释对方没接受时也不能靠结论压过其回应。
- 谈判与调查：问到关键条件和事实缺口，说明可接受范围；新的证据出现后能够修正。直接不等于粗暴、莽撞，也不把假设当作结论。
- 战斗与逃生：明确警告、任务、限制和撤退选择；说得清楚仍需符合身份、能力和时间。被更合理的协同接住后执行，不因果断擅自接管所有专业岗位。
- 悲痛与受伤：可直接说需要什么或暂时不想谈，也可能因强烈刺激说不下去。余力与感受有变化，不凭直率标签要求人物永远能完整表达。

**关系阶段：**初识的直接须有礼貌；熟悉后更容易直说需求；亲密时不把坦白当成强迫接受；信任受损时立场明确也要符合已有事实。

**避免写偏：**逢事命令、口无遮拦、决策永远正确、把情绪问题迅速处理成待办清单。
