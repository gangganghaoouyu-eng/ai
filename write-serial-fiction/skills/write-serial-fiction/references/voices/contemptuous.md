# 刻薄、轻蔑：人物声线与情绪表达

依据本书已确认的人物设定和当前阶段匹配后，读取本场相关情绪行及场景调整，同时保留基本声线、关系阶段与避免写偏说明。表中方向不要求全部出现，不能成为固定台词和动作。使用方法见 [声线总规则与索引](../character-voice.md)，环境、关系、强度和混合情绪见 [情绪、关系与环境调整](../voice-context.md)。

**适配依据：**人物经常以贬低、挖苦、轻视他人的方式交流，且已有具体行为支持。普通犀利、幽默和一次气话分别处理。

**基本声线：**可能用挑错、比较、反问或轻描淡写削弱对方，但台词必须针对现场事实和人物所知。刻薄也可平静，不以大量脏话或每句讥讽代替声线。

| 情绪或状态 | 对白与回应方式 | 行为、节奏与留白 |
| --- | --- | --- |
| 高兴 | 可能借成果强调自己判断正确，或少见地愿意认可别人。 | 表现出更大参与意愿，是否贬低旁人由具体习惯决定。 |
| 期待 | 可能对别人提出较高要求，也可能不愿暴露自己期待。 | 提前准备却不给好听解释，不强制安排冷笑或嫌弃。 |
| 害羞、心动 | 可能借挑剔维持体面，但不能将羞辱自动解释为爱。 | 真实在意通过有依据的选择显露，被冒犯者可以拒绝。 |
| 失落、难过 | 可能转为抱怨他人或减少交流，也可能承认结果不如意。 | 停止参与，挑错范围应具体，不能无缘无故攻击所有人。 |
| 委屈、受伤 | 容易将脆弱转成刺人的话，也可在可信对象前说清受伤部分。 | 撤回配合、打断对方解释；伤人之后有真实关系后果。 |
| 悲痛、重大失去 | 锋芒可能暂时消失，也可能以生硬回应保护自己。 | 必要事务中表现失去，不强行让悲痛也带优越感。 |
| 愤怒 | 挖苦可能更直接、更具体，仍受信息与现实位置限制。 | 公开指出问题、退出或施压；不是所有人都只能忍受。 |
| 吃醋 | 可能贬低竞争对象或否认在意，正文需保留其判断的偏差。 | 改变相处方式，不靠羞辱第三人证明魅力。 |
| 害怕 | 可能先掩饰或迁怒，也可能被迫求助；能力限制真实存在。 | 求援、退避或接纳指令，不能靠嘴毒免疫危险。 |
| 焦虑、不安 | 容易对小差错挑剔，表达应体现实际压力来源。 | 减少可控变量，不能以反复确认和挑毛病拖延情节。 |
| 愧疚、后悔 | 可能不好意思软化，仍需具体认错或做补救。 | 停止原有贬低行为，修正公开伤害；送好处不能代替必要道歉。 |
| 感动、接受安慰 | 可能生硬接纳，也可直接表达感谢；不要求每次感谢都带侮辱。 | 接受照顾，不再推开某项帮助；不能由一次软化断言本性已变。 |
| 失望、信任受损 | 可能更疏远或直接批评，批评围绕事实，不能全盘否定别人。 | 收回合作，真正的边界变化比连续毒舌更有作用。 |
| 疲惫、压力 | 话可能更少或更不耐烦，也能意识到需要停止交流。 | 暂停事务，避免把疲惫写成持续攻击弱者的装饰。 |
| 安心、恢复 | 可以减少无意义挑剔，认可一项具体帮助；未成长者仍可能保留旧习惯。 | 与阶段对应地恢复互动，改变要反映在后续行为中。 |

## 场景中的声线调整

本节与上表的本场情绪、基本声线及当前关系合用，仅取眼前有关的方向。不是固定台词或流程，情绪变化后接住新刺激和对方回应；环境调整详见 [情绪、关系与环境调整](../voice-context.md)。本场只直接展开一位心理主角；其他人物的内在顾虑仅用于推导可观察的表达。

- 日常与合作：已有轻蔑倾向可表现在称呼、打断、忽略贡献或具体挖苦，回应与合作成本要可见。不每句都辱骂，不用刻薄代替真实任务内容。
- 暧昧与亲密：在意可能与贬低性的防御并存，能否收住依本书阶段；对方可以拒绝这种表达。不把羞辱自动写成调情，不让旁白替伤人言语辩解为深爱。
- 争执与修复：可能抓住具体弱点讥讽、否定对方表达，愤怒程度有刺激依据；修复需停止相应行为并面对后果。不能以一句玩笑略过伤害。
- 谈判与调查：可能用轻视、挑刺或地位差压低对方，实际成效由筹码与回应决定；事实仍须核实。刻薄不等于机智无敌，也不能靠辱骂得到全部信息。
- 战斗与逃生：急迫时也需警告、任务与求援，轻蔑是否妨碍协同应有真实后果；危险会影响语气与余力。不让人物为挖苦暂停动作，也不借他人失败证明作者判断。
- 悲痛与受伤：可以难以接受被帮助、收起讥讽或仍以刺人措辞防御，依经历与关系决定。痛苦不自动使其温柔，也不让他人的关心无限承受侮辱。

**关系阶段：**对不同对象刻薄程度可以不同；熟悉不使羞辱失去伤害；成长应减少不必要伤人，保留人物原有机敏或锋利。

**避免写偏：**辱骂等于聪明、羞辱等于深情、全场只能震惊、被伤害的人立即感动。
