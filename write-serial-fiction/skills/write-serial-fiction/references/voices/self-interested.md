# 自利、趋利：人物声线与情绪表达

依据本书已确认的人物设定和当前阶段匹配后，读取本场相关情绪行及场景调整，同时保留基本声线、关系阶段与避免写偏说明。表中方向不要求全部出现，不能成为固定台词和动作。使用方法见 [声线总规则与索引](../character-voice.md)，环境、关系、强度和混合情绪见 [情绪、关系与环境调整](../voice-context.md)。

**适配依据：**人物反复优先考虑自身收益与责任，愿意根据利害改变投入。珍惜资源、明确报酬或一次拒绝帮助不直接等同于自私。

**基本声线：**较在意条件、代价、回报与退出方式；也可以礼貌、幽默或亲近。不能只用冷笑和钱财台词表现自利，利益范围按人物身份决定。

| 情绪或状态 | 对白与回应方式 | 行为、节奏与留白 |
| --- | --- | --- |
| 高兴 | 关注自己实际得到什么，可能因此更愿意配合或分享。 | 扩大有利合作，享受成果；不必每次都背后算计别人。 |
| 期待 | 问清收益和投入，愿意表态的程度与条件相关。 | 预留资源、争取机会，保留可行退出空间。 |
| 害羞、心动 | 真实好感与自身利害可同时存在，措辞可能仍顾及成本和体面。 | 愿意付出一部分原本不愿承担的事，不据此宣告彻底改变。 |
| 失落、难过 | 可能先谈损失与下一条路，也可因关系落空受到真实影响。 | 撤回投入或寻找替代方案，不将所有情感都写成不存在。 |
| 委屈、受伤 | 强调自己承担了什么、对方没有兑现什么；诉求可能有依据也可能偏颇。 | 要求补偿或停止付出，不让旁白替其合理化全部计算。 |
| 悲痛、重大失去 | 可以真正悲痛，同时仍在意现实后果与资源安排。 | 处理遗留事务，选择性承担责任；不能自动借机获利。 |
| 愤怒 | 对损失、被利用或无法退出反应明确，可能提出赔偿和条件。 | 终止合作、收回资源或采取有代价的反击，受实际能力限制。 |
| 吃醋 | 可能介意关注与资源分配，也可能有真实亲密需要。 | 争取位置、调整自己的投入；不把每段关系都写成交易。 |
| 害怕 | 更重视自己能否安全退出、保住重要事物。 | 优先自保，是否救人依据经历和利益；选择可以产生关系后果。 |
| 焦虑、不安 | 问清最影响自己风险的事项，然后决定承担多少。 | 缩减投入或增加明确条件，不循环核对同一风险。 |
| 愧疚、后悔 | 可能承认伤害，也可能先在意损失了信任；二者须在具体表现中区别。 | 有代价的补救可以支持成长，廉价承诺不能自动证明真心。 |
| 感动、接受安慰 | 得到不计回报的帮助后可能难以按旧方式回应，也可能仅接受便利。 | 是否主动回馈、是否愿意承担新代价由本书阶段决定。 |
| 失望、信任受损 | 收紧合作，重新谈条件或退出；私人失望未必全能折算成利益。 | 保留自己负责的部分，不能利用他人失信免除所有责任。 |
| 疲惫、压力 | 更倾向减少低收益事务，可能直接拒绝额外要求。 | 分配有限体力与资源，不能靠自利设定无限获得优势。 |
| 安心、恢复 | 愿意恢复有利合作，或在成长后增加少量无回报投入。 | 改善表现应来自真实选择，不凭一次被照顾改成无私。 |

## 场景中的声线调整

本节与上表的本场情绪、基本声线及当前关系合用，仅取眼前有关的方向。不是固定台词或流程，情绪变化后接住新刺激和对方回应；环境调整详见 [情绪、关系与环境调整](../voice-context.md)。本场只直接展开一位心理主角；其他人物的内在顾虑仅用于推导可观察的表达。

- 日常与合作：关注投入、回报和责任范围，愿不愿分担依实际成本与关系；高兴时可能认可有利结果。自利不等于每句话都谈钱或完全没有情感。
- 暧昧与亲密：投入与保留可以受现实顾虑影响，心动或吃醋仍有具体关系依据；提出需要时留给对方选择。不能把所有亲密都概括成交易，也不忽然无依据牺牲一切。
- 争执与修复：可能先界定损失和责任，之后是否顾及感受依当前阶段；认错须承认实际行为。不能用成本分析替自己免责，也不让对方自动接受交换式补偿。
- 谈判与调查：明确收益、成本、兑现条件和风险归属，信息选择受目标影响；判断仍可能失误。询问有实际用途，不为获得利益凭空知道秘密。
- 战斗与逃生：选择撤退、保护资源或协同的对象有设定依据，风险与后果可见；依能力简短表达限制。不是所有危险都必然抛弃同伴，也不凭趋利永远选中最优路线。
- 悲痛与受伤：现实安排和损失可能先进入表达，个人依恋仍可在具体触发中出现；是否接受照顾依条件与信任。不因自利抹掉痛苦，也不靠一次感动完成价值转变。

**关系阶段：**合作初期谈条件自然；亲近后可能有偏爱和非利益付出；失信后条件收紧；是否成长，要看其愿意承担哪些实际代价。

**避免写偏：**所有关系都只谈钱、利益永远算准、自保等于毫无感情、作者替不公平行为开脱。
