# 善于操纵、掩饰：人物声线与情绪表达

依据本书已确认的人物设定和当前阶段匹配后，读取本场相关情绪行及场景调整，同时保留基本声线、关系阶段与避免写偏说明。表中方向不要求全部出现，不能成为固定台词和动作。使用方法见 [声线总规则与索引](../character-voice.md)，环境、关系、强度和混合情绪见 [情绪、关系与环境调整](../voice-context.md)。

**适配依据：**人物有依据地选择信息、安排情绪展示或制造条件，以影响别人的判断与选择。普通礼貌、隐私保留和善于交际不能直接认定为操纵。

**基本声线：**会根据对象调整表达，可能选择性回答、强调某部分事实、提出附条件的关心。外在声线需结合其具体性格，不能所有操纵者都温柔假笑。

| 情绪或状态 | 对白与回应方式 | 行为、节奏与留白 |
| --- | --- | --- |
| 高兴 | 可以真实高兴，也可能放大喜悦以促成合作；两者不得无依据混判。 | 选择展示成果的对象与时机，但受现场信息限制。 |
| 期待 | 可能先让对方参与准备，再提出自己真正希望的选择。 | 设置可见条件或邀请，不能自动掌控对方后续反应。 |
| 害羞、心动 | 真心与策略可以并存，表达是否坦白由当下目的决定。 | 愿意放下一项策略或继续掩饰，都需要具体行为支持。 |
| 失落、难过 | 可能选择让某个人看见失落，也可独自受影响；不能每次都是演戏。 | 选择求助对象或收回投入，不靠旁白一口认定所有表情虚假。 |
| 委屈、受伤 | 可能突出自己受损的部分，引导对方承担责任；事实遗漏要有材料依据。 | 展示某个相关后果，其他人物可以追问、拒绝或另作判断。 |
| 悲痛、重大失去 | 可以真正悲痛，策略能力也会受损；利用事件须符合已有动机。 | 实际事务暴露余力与限制，不把悲痛写成自动启动的阴谋。 |
| 愤怒 | 可以压住直接指责，转为条件或让他人表态，也可能真实失控。 | 调整合作、利用已知信息施压，不能凭空制造筹码。 |
| 吃醋 | 可能通过邀约、信息选择或关系位置影响对方，而非直接承认。 | 不把制造误会、隔离他人自然解释成浪漫；后果与知情边界保留。 |
| 害怕 | 可能寻求更有利的依靠，选择性说出危险；也可能无法维持掩饰。 | 策略受时间与资源限制，不能保证所有人按预期救援。 |
| 焦虑、不安 | 更想掌握对方选择，但对未知只能作有限推测。 | 增加有依据的新安排，不能用反复核对套同一答案。 |
| 愧疚、后悔 | 可能真实认错，也可能强调自己的难处争取宽恕；区别靠后续行为。 | 是否承认遗漏、放弃好处、停止干预，比眼泪更能支持判断。 |
| 感动、接受安慰 | 无条件帮助可能让其暂时放下策略，也可能仅利用机会。 | 让他人保留选择、主动补足信息可体现改变；不立即洗白。 |
| 失望、信任受损 | 可能调整对象与方法，也可能开始更直接沟通，取决于成长。 | 合作撤回后保留实际代价，不能无限找来替代人选。 |
| 疲惫、压力 | 掩饰可能出现遗漏、说法不一致或失去耐心。 | 根据具体现场呈现一处失误，不让所有漏洞都巧合被发现。 |
| 安心、恢复 | 能否放下策略需阶段支撑，可能只对某个人减少掩饰。 | 真实改变落实为补足信息、接受拒绝、承担代价。 |

## 场景中的声线调整

本节与上表的本场情绪、基本声线及当前关系合用，仅取眼前有关的方向。不是固定台词或流程，情绪变化后接住新刺激和对方回应；环境调整详见 [情绪、关系与环境调整](../voice-context.md)。本场只直接展开一位心理主角；其他人物的内在顾虑仅用于推导可观察的表达。

- 日常与合作：有设定依据地选择展示哪些事实、怎样请求和怎样分配功劳，行为效果由对方回应呈现。不能把每句客气话都解释成操纵，也不由旁白读出其全部计划。
- 暧昧与亲密：亲近、退让或脆弱展示可能服务个人目标，也可能出现真实感受；依据本书事实区分。限知正文只呈现可接触的矛盾与选择，不自动宣判爱意真假。
- 争执与修复：可能转移焦点、选择性认错或争取对方回应，具体话术依身份与当前压力；对方可以识别、拒绝或只接受部分。不将操纵写成永远成功的万能技能。
- 谈判与调查：选择信息顺序、问题范围或可见证据影响判断，受已有信息和筹码限制；被追到事实缺口时表达可变化。不凭空知道秘密，不让配角必然照计划行动。
- 战斗与逃生：压力下只能使用现场可用信息与角色权限，简短协同、隐瞒或求助都需实际目的和可见后果。没有时间设计长篇话术，也不因擅长掩饰免疫恐惧。
- 悲痛与受伤：真实失去可能打乱展示习惯，接受帮助的方式依关系与目标；若利用脆弱影响他人，须有既有依据。不能把所有哭泣定性为演戏，限知不直接读取真伪。

**关系阶段：**不同对象可能看到不同表达；亲密不能证明真心，也不能证明所有表达虚假；转变应通过选择与代价展开。非视角人物的隐秘策略不能直接进入旁白。

**避免写偏：**作者全知揭穿、每句话暗藏阴谋、总能预测所有人、痛苦全部假装、一次感动彻底改性。
