# 理性克制：人物声线与情绪表达

依据本书已确认的人物设定和当前阶段匹配后，读取本场相关情绪行及场景调整，同时保留基本声线、关系阶段与避免写偏说明。表中方向不要求全部出现，不能成为固定台词和动作。使用方法见 [声线总规则与索引](../character-voice.md)，环境、关系、强度和混合情绪见 [情绪、关系与环境调整](../voice-context.md)。

**适配依据：**人物倾向整理事实、控制表达时机、依据条件选择行动。理性与温柔、幽默或外向可以并存，不能直接等同于高冷。

**基本声线：**条件与依据清楚，确定与推测分开，解释只覆盖对方需要知道的部分。私人交流可以自然，不必须像工作报告。

| 情绪或状态 | 对白与回应方式 | 行为、节奏与留白 |
| --- | --- | --- |
| 高兴 | 指出成功的具体部分，也能直接说愉悦，不只评价效率。 | 愿意给庆祝留时间，暂时放下工作节奏。 |
| 期待 | 说明希望和可行安排，同时保留不确定条件。 | 做适量准备，不将期待拆成无尽风险预案。 |
| 害羞、心动 | 可能先安排具体相处，随后才承认私人动机；也能坦白。 | 平时熟悉的表达出现局部不顺，不变成突然失语。 |
| 失落、难过 | 能区分结果与感受，暂时不愿分析也合理。 | 调整方案，保留一段情绪空间，不强迫自己立刻恢复。 |
| 委屈、受伤 | 先说具体事实，再说明其对自己的影响；不把情绪论证成法庭陈词。 | 暂停合作、提出边界，让说明产生实际变化。 |
| 悲痛、重大失去 | 惯常安排可能暂时支撑行动，也可能在关键细节上失效。 | 接受事务分担，处理能力受损；不凭理性轻易接受失去。 |
| 愤怒 | 措辞可能更短、更明确，指出行为与后果；可以有不完美表达。 | 结束无效争执或拒绝越界要求，不一边愤怒一边全知分析。 |
| 吃醋 | 区分事实、推测与自己的在意，必要时提出相处要求。 | 选择有效沟通而非调查一切，不把感情变成证据审查。 |
| 害怕 | 报告危险和限制，思考可行步骤；强烈恐惧会影响判断。 | 优先脱险与求助，不能因设定理性自动掌握全局。 |
| 焦虑、不安 | 只追问影响决策的未知部分，接受没有完美答案的现实。 | 完成准备后行动，不以严谨为由反复核对同一事实。 |
| 愧疚、后悔 | 说清责任与补救，允许真实懊悔存在，不急于用解释免责。 | 修正流程或行为，同时回应被伤害者的感受。 |
| 感动、接受安慰 | 可以承认帮助超出原本预期，表达具体感谢。 | 让他人接手事务，愿意说一点未整理好的感受。 |
| 失望、信任受损 | 调整可托付范围，说明事实依据；不把全部关系都宣布失效。 | 缩减合作，恢复需实际改变与时间支持。 |
| 疲惫、压力 | 表达可能更简略，分析能力下降；清楚提出需要暂停。 | 减少决策负担、请求分担，保留真实身体限制。 |
| 安心、恢复 | 能重新考虑较长远计划，也允许暂时不解决一切。 | 恢复适量任务与私人相处，减少无必要防备。 |

## 场景中的声线调整

本节与上表的本场情绪、基本声线及当前关系合用，仅取眼前有关的方向。不是固定台词或流程，情绪变化后接住新刺激和对方回应；环境调整详见 [情绪、关系与环境调整](../voice-context.md)。本场只直接展开一位心理主角；其他人物的内在顾虑仅用于推导可观察的表达。

- 日常与合作：用事实和可行安排组织交流，高兴时可表达具体满意之处；余力允许时也能谈个人感受。不把普通对话持续写成步骤清单。
- 暧昧与亲密：能说明想相处的安排，也可承认自己尚不确定或紧张；心动不必全部翻译为利弊分析。吃醋时说清触发事实与个人需要，不计算对方的感情价值。
- 争执与修复：分清事实、责任和未明部分，但仍回应对方受到的影响；愧疚既认错又补救。理性不等于没有情绪，更不代表其解释一定正确。
- 谈判与调查：在掌握的信息范围内比较条件、提出核实路径，修正依据不足的判断；时间紧时只讲关键。不能每次完整推演全部结果或自动看透隐瞒。
- 战斗与逃生：依视野、专业和余力做有限判断，提供可执行的协同；恐惧与伤势会打断计划。现场不作完整战术演讲，也不凭克制忽略风险。
- 悲痛与受伤：可能先处理必须完成的事务，再在具体刺激下显出阻滞；需要时也可直接求陪伴。不把情绪处理成报告，不在章末得出苦难的道理。

**关系阶段：**初识围绕可靠信息；信任后愿意表达不确定与脆弱；关系受损时收紧托付；成长可以增加情绪表达能力，不能变成感情专家。

**避免写偏：**人人心理分析、任何情绪都讲道理、永远毫无失误、冗长分条演说。
