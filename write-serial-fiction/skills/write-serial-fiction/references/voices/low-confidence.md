# 自卑、缺乏自信：人物声线与情绪表达

依据本书已确认的人物设定和当前阶段匹配后，读取本场相关情绪行及场景调整，同时保留基本声线、关系阶段与避免写偏说明。表中方向不要求全部出现，不能成为固定台词和动作。使用方法见 [声线总规则与索引](../character-voice.md)，环境、关系、强度和混合情绪见 [情绪、关系与环境调整](../voice-context.md)。

**适配依据：**已有设定或经历显示人物容易否定自身价值、担心给别人添麻烦、怀疑是否配得到善意。不能把经济处境或一次紧张直接等同于自卑。

**基本声线：**可能先缩小自己的请求、给对方退出空间，或用过分轻松的表达掩饰认真。不是所有句子都自我贬低；在擅长领域仍可清楚坚定。

| 情绪或状态 | 对白与回应方式 | 行为、节奏与留白 |
| --- | --- | --- |
| 高兴 | 对肯定有反应，但可能先说成运气或别人的帮助；逐步成长后可以直接接受夸奖。 | 珍惜得到的机会、认真完成后续；不要每次马上否定自己。 |
| 期待 | 可能先提出较小的愿望，或试图给请求找合理理由。 | 提前付出额外准备，降低自己表达的要求；不让期待变成连续索要保证。 |
| 害羞、心动 | 想靠近又怕理解错，表达常留余地；意外表白明显超出当前预期时可失语、结巴、误解或作必要确认。 | 得到澄清后可以仍然局促，接受靠近与恢复流畅不必同时发生；不持续索取同一保证，关系确认不立即治好自卑。 |
| 失落、难过 | 容易先把失败归给自己，措辞缩小诉求；可以被事实促使重新判断。 | 继续补做事情、取消原本想提出的请求；不靠长段自责重复一个结论。 |
| 委屈、受伤 | 可能先辩解自己没有想添麻烦，真正委屈随后才出现；也能在底线处拒绝。 | 收回求助动作或把事务揽回自己；不得永远任人伤害。 |
| 悲痛、重大失去 | 可能纠结自己当时没有做到的事；正文要有具体经历支撑。 | 试图完成失去者留下的事务，或难以碰某个有依据的物件；不凭空增添罪责。 |
| 愤怒 | 愤怒可能与害怕被讨厌同时存在，话先克制后变直接；不能自动立刻道歉。 | 终于停止替对方做事、把一项要求说完；反抗可以有后续顾虑。 |
| 吃醋 | 担心自己被比较，可能先退让或问自己在关系中的位置；关键处可表达不舒服。 | 减少主动靠近，随后作出选择；不反复问“你是不是不喜欢我”。 |
| 害怕 | 可能连求助都担心成本，先报告自己还能做什么；危险中仍可直接求救。 | 尽量自理后接受帮助；不能为性格强行拖延必要行动。 |
| 焦虑、不安 | 更在意自己是否做错、是否拖累进度；问题应针对未明事项。 | 多做准备或反复整理可简洁带过；不能将已确认事实重新核对成整场对白。 |
| 愧疚、后悔 | 自责范围容易扩大，表达要区分实际责任与人物的错误归因。 | 想补偿过多，可能需要限制付出；不能由旁白默认其全部自责都正确。 |
| 感动、接受安慰 | 可能难以相信自己也能被照顾，但有明确善意后应允许接纳向前推进。 | 接受具体帮助、第一次提出一个小需要；不靠反复拒绝关心延长场景。 |
| 失望、信任受损 | 可能先怪自己期待太多，也可能意识到对方确实失约并设边界。 | 停止某项单方面付出；成长通过具体变化体现，不突然完全自信。 |
| 疲惫、压力 | 更难维持迎合，可能说出以前不敢说的限制，也可能减少解释。 | 没有余力继续代做事务，开始求助；不把自卑写成无限劳动能力。 |
| 安心、恢复 | 对自己的判断更有把握，能接受肯定或提出小要求。 | 保留一项自己的选择，不再立刻让给别人；改善仍可不稳定。 |

## 场景中的声线调整

本节与上表的本场情绪、基本声线及当前关系合用，仅取眼前有关的方向。不是固定台词或流程，情绪变化后接住新刺激和对方回应；环境调整详见 [情绪、关系与环境调整](../voice-context.md)。本场只直接展开一位心理主角；其他人物的内在顾虑仅用于推导可观察的表达。

- 日常与合作：请求可能留余地，面对熟悉且擅长的任务可以清楚表达；得到有效接纳后继续参与。高兴不必立刻否定自己，也不每轮道谢或道歉。
- 暧昧与亲密：期待靠近时可能缩小请求、担心占用时间；意外表白可依当前阶段与刺激强度出现震惊、失语或必要确认，具体按 [回应速度与情绪消化](../dialogue-craft.md#回应速度与情绪消化) 处理。对方明确回应后允许接受一小步，措辞和行动仍可局促，不为推进剧情迅速恢复冷静。吃醋或不安表达实际需要，不反复盘问自己是否值得被喜欢。
- 争执与修复：受伤时可能先退让，但也能在有依据的成长后说清界限；愧疚只承认实际责任。对方解释后依新信息回应，不自动包揽全部错误或全盘否定自己。
- 谈判与调查：可能先准备依据、试探能否提出条件，但不必放弃应有利益；害怕说错时区分确定事实与推测。能力与经验已成立的部分仍可专业，不全程怯懦。
- 战斗与逃生：报告自己能承担的任务和真实限制，求援可以直接；急迫时不长篇解释自己会拖累谁。可靠指令得到理解后执行，不反复索求鼓励才肯行动。
- 悲痛与受伤：可能怕给人添麻烦而缩小需求，但有帮助后可以明确接受；自责需要实际事件依据。安慰不立即治好长期自卑，也不让人物持续驳回每一次善意。

**关系阶段：**早期靠缩小请求自保；稳定善意可以逐步增加表达；被背叛后旧顾虑可能重现，但不能抹掉已经获得的全部成长。

**避免写偏：**所有情绪都变成道歉、永远觉得自己不配、靠一次表白治好自卑、毫无能力与底线。
