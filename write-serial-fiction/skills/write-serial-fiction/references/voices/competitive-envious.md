# 好胜、善妒：人物声线与情绪表达

依据本书已确认的人物设定和当前阶段匹配后，读取本场相关情绪行及场景调整，同时保留基本声线、关系阶段与避免写偏说明。表中方向不要求全部出现，不能成为固定台词和动作。使用方法见 [声线总规则与索引](../character-voice.md)，环境、关系、强度和混合情绪见 [情绪、关系与环境调整](../voice-context.md)。

**适配依据：**人物对排名、认可、资源或关系中的比较较在意。正常竞争与偶发嫉妒不足以推定长期恶意。

**基本声线：**容易关注谁做得更好、谁获得了认可，表达可能强调自己的投入。竞争对象和在意领域需有依据，不把每件小事都升级为胜负。

| 情绪或状态 | 对白与回应方式 | 行为、节奏与留白 |
| --- | --- | --- |
| 高兴 | 愿意说出成果，可能在意认可来自谁；可正常分享而非必然炫耀。 | 展示自己做过的部分，接受或争取评价，不强行贬低别人。 |
| 期待 | 想争取机会、名次或被选择，问清相关条件。 | 练习、准备、主动参与，不自动使用破坏对手的手段。 |
| 害羞、心动 | 希望呈现自己擅长的一面，担心被比较，也可真实赞赏对方。 | 争取一起完成事情的机会，不把好感写成单纯获胜。 |
| 失落、难过 | 容易注意别人得到而自己没有的部分，可坦白不甘。 | 加紧准备、暂时退出比较或改变目标，选择符合阶段。 |
| 委屈、受伤 | 强调自己的投入被忽略，要求评价或待遇公平。 | 停止额外工作、拿出实际成果，不能捏造别人毫无付出。 |
| 悲痛、重大失去 | 比较意识可能暂时消退，或纠缠在失去机会与身份上。 | 失去后的实际空缺决定反应，不强行在悲痛里继续争胜。 |
| 愤怒 | 针对不公平、被超越或被贬低说话；可能尖锐但应有具体内容。 | 争取复核新争议、正面竞争或不当报复，各有现实后果。 |
| 吃醋 | 对他人获得关注较敏感，表达可要求公平或争取位置。 | 增加表现或退出互动，不让对方沦为胜负奖品。 |
| 害怕 | 担心失去位置，也可能承认实际危险更重要。 | 保护自己已有资源，必要时接受合作，不因好胜拒绝一切援助。 |
| 焦虑、不安 | 把注意力放在准备和机会变化上，问清尚未明确的标准。 | 提高投入或缩小目标，不反复要求别人比较谁更重要。 |
| 愧疚、后悔 | 若竞争伤人，可承认行为与损害；不能仅为没赢而后悔。 | 归还机会、撤回谣言或改正不公平行为，具体取决于情节。 |
| 感动、接受安慰 | 被看见实际付出时可松动，也可能难以接受失败后的安慰。 | 接纳协作或停止一次无意义竞争，不突然放弃所有追求。 |
| 失望、信任受损 | 可能认为认可分配不公，须区分确有偏袒与自己的判断。 | 调整合作或另寻机会，不能由旁白默认每次嫉妒都有道理。 |
| 疲惫、压力 | 仍想维持表现，表达可能急切；可以意识到投入已超出能力。 | 减少任务、接受暂时落后，不凭意志无限工作。 |
| 安心、恢复 | 不必靠比较证明自己，能认可具体成果或别人的贡献。 | 把注意力放回目标，成长幅度由已发生经历决定。 |

## 场景中的声线调整

本节与上表的本场情绪、基本声线及当前关系合用，仅取眼前有关的方向。不是固定台词或流程，情绪变化后接住新刺激和对方回应；环境调整详见 [情绪、关系与环境调整](../voice-context.md)。本场只直接展开一位心理主角；其他人物的内在顾虑仅用于推导可观察的表达。

- 日常与合作：比较意识可以影响认领任务、评价成果和参与意愿；高兴时可能更在意自己的贡献。竞争与长期善妒分清，不每次都找人贬低。
- 暧昧与亲密：吃醋可能集中于被比较或被忽略的具体事件，表达程度依关系和面子；对回应有实际变化。不自动限制交往，不靠反复审查证明在意。
- 争执与修复：可能关注输赢、认可和谁占优势，受伤之处需要具体依据；若承认责任，补救不能只是争取道歉比赛的胜利。对方可以拒绝其比较框架。
- 谈判与调查：想争取更好条件、抢先发现或证明能力，关注点受目标影响；事实核实不能因好胜省略。落后时可能失态，但不必自动害人或总能翻盘。
- 战斗与逃生：表现欲与竞争可影响选择，仍受本书能力、职责和风险限制；失败或恐惧可能迫使求援。后果真实，不为让他赢让同伴与对手集体失去判断。
- 悲痛与受伤：比较习惯可能暂时失去作用，也可能因具体丧失而加重自责或不甘；按既有经历展开。不把他人的悲痛变成无缘由争宠，安慰不立刻消除长期比较倾向。

**关系阶段：**竞争关系与亲密关系分别处理；被稳定认可可以减少部分比较；失信后重建依据具体承诺，不能让对方无限证明偏爱。

**避免写偏：**所有嫉妒都变成恶毒、争强就永远破坏别人、靠关系争夺替代人物自身目标。
