# 开朗活泼：人物声线与情绪表达

依据本书已确认的人物设定和当前阶段匹配后，读取本场相关情绪行及场景调整，同时保留基本声线、关系阶段与避免写偏说明。表中方向不要求全部出现，不能成为固定台词和动作。使用方法见 [声线总规则与索引](../character-voice.md)，环境、关系、强度和混合情绪见 [情绪、关系与环境调整](../voice-context.md)。

**适配依据：**喜欢主动接话、分享经历、参与集体活动，表达兴趣通常较直接。活泼不要求外放吵闹，也不要求没有心事。

**基本声线：**措辞具体、交流主动，容易提出邀请、分享发现或追问有趣细节。可以说几句连贯的话，但每句有新内容；不靠感叹号、撒娇词和连续语气词表现活力。

| 情绪或状态 | 对白与回应方式 | 行为、节奏与留白 |
| --- | --- | --- |
| 高兴 | 愿意说清自己高兴的缘由，邀请对方参与；对回应有兴趣，不只顾着独白。 | 将新发现递给对方看、主动腾出位置或改变原计划去分享；强度较低时只需一处主动。 |
| 期待 | 说具体想做的事、时间或准备，既有兴致也能接受现实条件。 | 提前整理用品、留出时间；等待有新进展再提，不每隔几段问一次是否会来。 |
| 害羞、心动 | 平时自然的接话可能突然绕远、改口，也可能大方夸赞后才意识到亲密。 | 已伸出去的手改变落点、原本并排走的步伐稍慢；变化贴着具体触发，不每次都脸红。 |
| 失落、难过 | 可以直接说遗憾，也可能试着换个安排；愿意接话却不再主动延伸。 | 收起原本准备分享的东西，做完手里的事；不必立刻变成完全沉默的人。 |
| 委屈、受伤 | 更想让对方听懂被误解的部分，可能先急着纠正，再说真正介意的事。 | 正在进行的分享中止，东西不再递过去；关键解释充分写，之后不重讲同一委屈。 |
| 悲痛、重大失去 | 日常活力可能消失，话题难以接续；也可能坚持谈具体事务来支撑当下。 | 原有习惯留下空缺，如少准备了一份东西；不用强行玩笑或一次安慰恢复热闹。 |
| 愤怒 | 直接指出具体行为，语速可能加快；仍能有针对性地回应，不能只连发责问。 | 放下手里的活、转过身说清问题，或离开争执位置；动作不必摔东西。 |
| 吃醋 | 可以借轻松问法试探，也可以坦白自己原本的期待；表达程度取决于关系。 | 不再积极加入某段谈话，或改动原先同行安排；不能自动宣称对方属于自己。 |
| 害怕 | 更容易寻求同伴、直接问该怎么做；说话可以简短，不硬维持活泼。 | 靠近可信的人、让出通道、抓住可用支撑；只写视角可见的应对。 |
| 焦虑、不安 | 想尽快推动事情，可能连续提出不同办法；答案明确后选择行动。 | 提前完成准备、尝试联系可提供新信息的人；不能重复询问已明确情况。 |
| 愧疚、后悔 | 能主动开口说明自己的行为与补救；不好意思也不靠插科打诨敷衍。 | 处理自己造成的麻烦，给对方选择是否接受帮助的空间。 |
| 感动、接受安慰 | 可主动感谢、分享更私人的感受，也可能短暂接不上平时的玩笑。 | 接过实际帮助，愿意坐近或让对方参与事务；不必立即表白或关系升级。 |
| 失望、信任受损 | 保留礼貌和普通交流，减少分享私事；愿不愿解释取决于修复阶段。 | 不再默认替对方留位置或安排同行；不给旁白添加“她再也不信任何人”的结论。 |
| 疲惫、压力 | 主动性下降，表达更直接地围绕必要事项；仍可能偶尔接一个轻松话题。 | 缩减事务、坐下歇息或请求分担；不让每轮都重新询问体力状态。 |
| 安心、恢复 | 重新愿意分享眼前事情，轻松感逐步回来；具体难题仍未解决时保留顾虑。 | 某个熟悉习惯重新出现，能参与一小段活动；不一口气恢复全部活力。 |

## 场景中的声线调整

本节与上表的本场情绪、基本声线及当前关系合用，仅取眼前有关的方向。不是固定台词或流程，情绪变化后接住新刺激和对方回应；环境调整详见 [情绪、关系与环境调整](../voice-context.md)。本场只直接展开一位心理主角；其他人物的内在顾虑仅用于推导可观察的表达。

- 日常与合作：高兴时主动分享具体发现并邀请参与；失落时可以仍接话，却减少主动延伸。边做事边给下一步安排，不持续制造热闹或重复问同伴是否开心。
- 暧昧与亲密：期待时可主动提出同行或分享，心动时可能改口，也可能坦率夸赞；吃醋从被忽略的安排或自己的期待切入，依关系决定说多少，不自动占有。
- 争执与修复：受伤时急于让对方听懂具体误解，愤怒时直接指出行为；对方澄清后接新内容，道歉时说明补救，不反复重讲委屈，也不靠撒娇取消分歧。
- 谈判与调查：愿意主动提问、试着拉近交流，但现实利益和疑点仍需说清。焦虑时可能提出几个不同办法，得到新信息后选一项执行，不把活泼写成无警惕。
- 战斗与逃生：害怕时可直接找可信同伴求助、报告自己能做什么；急迫时话短，不硬接玩笑。人物主动参与的方式依能力与职责，不因开朗总是冲在最前。
- 悲痛与受伤：原有分享习惯可以中断，也可能借具体事务撑住当下；接受安慰后只恢复有余力的一部分。关心按已知情况安排，不强行逗笑或立刻恢复活力。

**关系阶段：**初识时活跃可主要围绕公共话题；熟悉后分享具体生活；恋人之间可以直接谈期待；关系受损后仍可能外向，但不再把私人内容交给对方。

**避免写偏：**不停叽叽喳喳、遇到任何情绪都撒娇、靠跳脚鼓脸表现活泼、把开朗写成没有判断力。
