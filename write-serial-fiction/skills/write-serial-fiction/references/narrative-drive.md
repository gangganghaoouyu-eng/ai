# 全书以对白推进主线，场景按处境调整

## 全书的推进原则

全书优先通过实际对白推动主线：重要信息怎样传给他人、各方为什么不肯让步、合作条件怎样改变、人物接受或拒绝什么、下一步由谁去做，尽量发生在有来有往的交流中。不要用“他们商量好了”“她解释了经过”“两人达成共识”等概括省掉章纲要求展开的核心谈话。

对白把人物当下的口气说完整，叙述把动作和情绪接顺。依 [连接词、语气成分与小修饰词](expression-craft.md#连接词语气成分与小修饰词) 和 [口语化与人物口气](colloquial-expression.md) 自然保留商量、反问、让步、强调与动作延续，连接和小词可以比极简表达稍多一些。对白之后接实际选择与后果。回答可以改变方案，也可以使合作失败、暴露分歧或暂时留下问题；不要求每场成功沟通。不把所有台词改成汇报、说明书或内心独白，也不设对白字数占比、每页发言数或固定对答轮次。

场景有不同的推进需要。遇到即时危险、独处、重大失去或以含蓄行动推进关系的时刻，动作、心理、环境和沉默可以承担主要变化。场景主次改变后，仍沿用本书的人设、当前阶段、视角范围和同场单一心理主角的边界；需要交流时再让人物说此刻必要的话。

## 不同场景由什么承担主要变化

| 场景 | 主要推进方式 | 对白与描写的作用 |
| --- | --- | --- |
| 商议、谈判、合作、立场冲突 | 直接对白交换信息、改变条件并产生决定。 | 行动呈现筹码、距离和实际执行；叙述只补当前理解所需的事实。 |
| 日常事务与共同准备 | 做事时交流，以新的安排、分工、邀请或分歧推进。 | 不要求每轮产生危机；日常也不能长时间重复同一种关心。 |
| 误会、争执、修复、表白 | 关键意思由人物亲口表达，对方实际回应。 | 行动能提供证据或表达分寸，但不能自动代替必须讲清的问题。 |
| 战斗、追逐、逃生 | 动作、位置、环境变化与即时后果为主。 | 对白只承担必要警告、请求和协同；不在危险中长篇解释情绪。 |
| 暧昧与尚未确认的靠近 | 含蓄动作、距离、选择与真实回应可独立推进。 | 人物需要试探或说明时才说；不让台词或旁白把已可感受的含义再讲一遍。 |
| 调查与发现 | 可感知线索先出现，再由询问、辨认、推断和行动展开。 | 对白推动核实与选择，不凭空制造证据，不把推测说成已确认事实。 |
| 独处、等待、悲痛 | 视角人物的实际感受、事务、记忆和行为可以为主。 | 不为对白偏好硬添旁人、电话或自言自语；有交流机会时依本场余力表达。 |
| 路程、重复劳动与转场 | 用必要叙述压缩无关重复，接到下一处有变化的场景。 | 不省掉本章承诺的关键事件与核心谈话。 |

混合场景随着刺激变化调整：交涉突然遇袭，先处理危险；脱险后再谈尚未处理的分歧。不能一边躲避攻击，一边保持平时完整的谈心节奏。具体写法见 [不同场景的写法](scene-writing.md)。

## 叙述、心理与对白各自补什么

叙述交代当前视角能够接触的位置、物件、身体动作、环境刺激和实际后果。不能代为宣告他人的真实动机、关系性质、事件意义或未来走向。

本场唯一心理主角的心理可以充分写，呈现其此刻实际产生的期待、犹豫、误会和判断；可采用符合人设的第一人称口语独白，心理与对白不要原意重复。其他人物通过观察、猜测、对白、微表情和行动回应，旁白不揭晓其隐秘判断；读者看到的心理不自动成为其他人物已知的信息。具体采用 [视角、心理与留白](perspective-restraint.md)。

对白承担人物眼前有理由交流的部分。双方已知且没有争议的背景不为解释设定重新背诵；独有知识须有分享理由，隐瞒与误会仍按人物各自的知情范围处理。没有有效答复的问题可以继续追问，已明确的事依旧遵守不重复核对规则。

## 在场景中保留不同声线

先按 [人物声线](character-voice.md) 匹配本书当前人设，再把对应情绪与场景调整合用。确定这个人眼前想做什么、面对谁、能说多少、能否被旁人听见，以及时间、体力和情绪允许他怎样表达。

紧急时大家都可能说短句，但关注的内容、求助方式、承担风险的选择和对人的称呼仍可不同。谈判时各人都可能讲条件，但不能突然都有同样的理性口吻。情绪与环境只调整本人的表达，不替换其性格与经历。

全书执行 [视角、心理与留白](perspective-restraint.md)；完整连载章节执行 [章末钩子与收束](chapter-hooks.md)。对白偏好不能覆盖这些边界。
