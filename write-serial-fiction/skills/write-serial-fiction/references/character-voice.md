# 人物声线：按本书与当前阶段决定怎么说

声线包括措辞、句式、信息取舍、语气、回应方式和沉默。它来自本书的人物及经历，不能靠每个人分配一句口头禅或一种固定句长来区别。

## 从当前处境推导表达

写对白和内心表达前，依据已经读取的本书资料，在创作中掌握以下因素，不向用户输出声线表：

- **稳定基础：**年龄、身份、教育、成长环境、职业、价值取向、说话习惯和人物设定。用这些因素约束措辞，不以身份标签代替具体人物。
- **当前阶段：**人物此刻的认知、经历造成的变化、尚未解决的伤害与顾虑，以及现在能承受或愿意承认什么。以后会成长成什么样，不能直接套到现在。
- **面对谁：**双方当前关系、信任程度、亲疏、权力差异、是否有旁人在场。对同伴、陌生人、长辈或曾经伤害自己的人，表达可以不同。
- **知道多少：**亲眼见到、别人告知、自己推断、误会或完全未知的信息分别处理。措辞中的确定程度必须匹配依据。
- **眼前想做什么：**询问信息、求助、试探、拒绝、解释、隐瞒、讨好、争取合作或守住底线。每轮回应承接对方刚刚给出的信息和压力。
- **身处什么环境：**公开或私下、能否被旁人听到、任务分工、距离与可用空间、危险迫近程度，以及时间、体力和伤势限制。环境决定表达机会，不让所有人因此使用同一套口吻。
- **此刻状态：**疲惫、疼痛、恐惧、羞涩、愤怒、喜悦及现实紧迫程度，影响句长、停顿和表达完整度，不抹掉原有性格。

这些因素共同决定这一次该说什么、怎样说、说到哪里。把当前商量、抱怨、让步、嘴硬与情绪分量说完整，连接与小词可以比极简表达稍多一些；寡言、克制也可以有自然口气，不靠删净小词表现性格。不能先写一套通用深情或争执台词，再给人物换名字。

## 让阶段变化在话里发生

称呼、玩笑尺度、请求方式、解释意愿、承诺强度和对沉默的接受程度，都应符合当前关系。初识不能直接使用后期亲密称呼；信任破裂后不能凭一次拥抱恢复从前；人物尚未承认的情感不能突然由旁白代为确认。

声线允许渐变：经历某件事后更愿意解释，或暂时变得谨慎，需要由已发生的经历支持。关键转变可通过这次具体谈话发生，但不能跳过对方的回应和未解决的问题。

同一个人物对不同对象会有不同表现，稳定基础仍应可辨。嘴硬的人可以用实际安排表达关心，寡言的人在必须解释时可以说完整的话，能说会道的人也会在真正受伤时说不下去。

## 避免常见替代品

- 冷静不等于全程两字回应，强势不等于喊叫，温柔不等于每句哄人，聪明不等于随时发表完整分析。
- 朴实不等于没有思想，职业人物不等于持续使用术语，少年不等于只会俏皮话。按实际经历选择他们会使用的概念与比喻。
- 不让所有人物轮流说格言、心理咨询式劝慰或结构完整的演讲。表达充分与高度自省不是一回事。
- 句长和发言分量由当前目的、对象与状态决定。健谈的人也不需要重复同一意思，寡言的人可以在必要时完整解释；不靠啰嗦、辞藻堆砌或固定套句表现性格。
- 日常口语与网络表达按本书人物的年龄、成长环境、时代、接触范围、对象及当前情绪选择，见 [口语化与人物口气](colloquial-expression.md)。资料有相应依据时可以自然使用，不要求逐词注明；不为区分人物硬加方言、怪癖或重复口头禅。
- 不让人物替作者解释世界设定、未来情节或本场谈话的意义。双方早已知道的背景没有交流理由时可以省略。

## 分类参考的共同边界

这组参考提供人物在不同情绪下可采用的表达方向。小说已经确定的人物设定、经历、年龄、身份、称呼、关系阶段和当下处境优先。不能因为读取某一分类就给人物新增经历、改变关系，或让人物突然具备后期的表达能力。

人物可以同时有几种倾向。开朗、自卑、克制、幽默等分别影响不同方面；每场选择与当前人物最有关的部分组合使用，不把所有特点同时表演出来。反应也可以因压力、对象和经历而变化，表中的写法不要求全部出现。

声线不仅是语气，也包括说什么、避开什么、怎样回应、句长、信息的确定程度，以及说完后采取什么行动。动作来自当前事务和环境，不能按身体部位轮换；可以直接接台词，不必每轮都配动作。需要写眼神、哭泣、笑容或唇角时，合用 [眼神、唇角与微表情](facial-expression.md) 的相关段落，以及 [表情的显露与收回](voice-context.md#表情的显露与收回) 中匹配倾向；由本场情绪、对象、阶段和环境决定变化，不能将某个性格绑定一种固定表情。

表中的内在顾虑用于推导行为；只有本场唯一心理主角的念头可以直接展开，其他人物的感受通过可感知的行为、台词和后果呈现。心理可用符合本人经历、当前阶段与情绪的第一人称口语独白，不将参考库的动机说明复制为作者分析。同场不轮流进入不同人物内心，人物观察与猜测可以不准确；具体采用 [视角、心理与留白](perspective-restraint.md)。

回应的流畅程度、速度与恢复时间依当前阶段的人物性格、关系和情绪强度决定，具体采用 [回应速度与情绪消化](dialogue-craft.md#回应速度与情绪消化)。允许有依据的失语、结巴、误解、改口和必要确认；得到明确回应后，情绪仍可影响表达与行动，不让所有人立刻理解、冷静或完整说出自己的需要。

同一件事或身体情况已经得到有效答复且含义被理解后，沿用答案；必要确认按上述规则处理，不能因自卑、吃醋或多疑持续索取同样的保证。新信息、真实变化或尚未答清的问题出现时，仅处理新增或未明部分。

## 匹配与按需读取

1. 先按既有资料顺序读取本书当前章纲、卷纲、最新适用阶段文件、相关人物设定和正文接点；涉及旧事时回读相应旧阶段资料。
2. 优先识别设定明确写出的倾向。未明示时，依据已经发生的连续行为和当前阶段判断，不能因为一次沉默就认定内向，一次退让就认定自卑，一次嫉妒就认定人物长期善妒。
3. 确认本场真正的情绪与触发原因。需要区分失落、被误解的委屈、关系受损的伤心和重大失去的悲痛，不按标签自动升级强度。
4. 读取对应性格模块中与本场情绪有关的段落、相应的场景调整，同时保留该模块的基本声线、关系阶段和避免写偏规则。把情绪触发原因与当前环境合用：同样关心，危险中可能先协同脱险，私下才有空间说明担心；不能直接搬用情绪表的一条完整反应。需要面部描写时，再取微表情参考中对应的眼神、哭泣或唇角段落，用当前人设决定分量，不先给情绪套一张通用的脸。情绪或场景转变后，按新刺激调整，不把整章锁成同一种状态。
5. 复合人物先选当前主要倾向，再补确有依据的其他倾向。例如外向但自卑，可用开朗的交流方式结合自卑的顾虑；不能把两个模块的动作和台词直接拼接。
6. 表里没有适合的反应，或本书原有声线更明确时，依据原设定写作。人物可以合理地表现出分类中较少见的一面，不为了分类牺牲具体人物。
7. 台词示意用于理解表达分寸，不照抄、不分配为口头禅，不将示例人物或事件带入其他小说。

先在下表匹配本书人设，再实际读取对应文件中本场相关情绪、场景调整，以及基本声线、关系阶段与避免写偏说明。判断类型不需要向用户展示标签、评分或声线表。尚无充分依据时沿用本书资料与本文件共同写法，不强行归类。

写人物表达时，读取 [情绪、关系与环境调整](voice-context.md) 中本场相关的场景条件；涉及关系分寸、情绪强度、疲惫状态或混合转变时，再采用相应部分。仅在用户要求示意或需要辨明复合类型与阶段差异时，读取 [匹配与写法示意](voice-examples.md) 的相关段落。

每类均有十五项情绪与状态，包括高兴、期待、害羞心动、失落难过、委屈受伤、悲痛失去、愤怒、吃醋、害怕、焦虑不安、愧疚后悔、感动与接受安慰、失望与信任受损、疲惫压力、安心恢复。只读取和使用本场有关部分，情绪转变时接住触发事件与回应，不把整章锁成同一种状态。

同一版参考已实际读取且仍在当前上下文中时可以复用。读取不能替代本书资料；后期人设不得倒灌到前期，作者知道的动机不能越过本书视角与同场单一心理主角的边界。声线细化仍受留白、避免模板与重复核对规则约束。对白简洁指不重复绕话，完整口气与自然连接应当保留。
