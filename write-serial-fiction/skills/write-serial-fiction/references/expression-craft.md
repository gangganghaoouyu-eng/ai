# 用词、句式与对白前动作

本文件用于小说正文、人物台词和内心表达的写作、扩写与润色。风格要求直接落实在正文中，不另设检查模块、词频报告或保存流程。用户指定原话、作品既有声线和有意义的回响优先。

## 连接词、语气成分与小修饰词

**对白把人物当下的口气说完整，叙述把动作和情绪接顺。**默认采用较舒展、自然的表达，连接词、承接成分、语气成分和小修饰词可以比极简写法稍多一些。让话语带着人物此刻的商量、抱怨、惊讶、嘴硬、让步或急迫，让动作接住前一句留下的刺激与尚未消退的情绪。

“给、来、就、都、再、还真、但是、能不能、得”等小词，即使没有增加新的事实，也可能承担口气、轻重、节奏和回应关系。只要读起来顺、分量贴合当前人物，就应自然保留或补足；不要为追求简洁把整场谈话压成干硬的任务通知，也不要把叙述削成一串孤立动作。删的是重复绕话、空泛解释和机械填充，完整的说话口气与连贯节奏需要保留。

连接和修饰取自本场真实的动作、对象、时间、身体余力与情绪。使用分量依本书当前阶段的人设、场景和实际反应变化，顺口不等于擅自改动时间、态度或行为。已经自然流畅的短句可以保留；连接也可来自句序、共同事务、回应和动作延续，不设逐句加词的配额。

### 依据实际关系选择成分

| 作用 | 可参考的成分 | 使用依据 |
| --- | --- | --- |
| 先后、优先与接续 | 先、再、紧接着、随后、接着、便、就、刚一……就…… | 依真实顺序、分工或优先事项使用。“你先去取货，我留在这儿等电话”可以表示先处理的一项分工，不意味着两个人必须串行行动。 |
| 等待、费力或条件满足 | 好不容易、总算、可算是、这才、才、终于 | 前文确有阻碍、等待、努力或条件变化。“这才”不凭空制造迟疑，“终于”不把普通动作夸成艰难过程。 |
| 时间与当前处境 | 这会儿、眼下、刚才、临走前、到这时候、回头 | 时间参照来自已给出的场景，不虚构过去经历或未来既成事实。 |
| 状态与情绪延续 | 仍、还、依旧、还没缓过劲儿、一时半会儿、到底还是 | 原状态确实持续或影响接下来的行为。理解了答复之后仍可难过，但不重新索取同一保证。 |
| 转折、让步与条件 | 但是、可是、却、倒也、也不是不行、不过、你得先…… | 表达本场真实的退让、限制或分歧。让步要有实际让步，不能只为了丰富句式临时改变立场。 |
| 出乎意料或刚听明白 | 偏偏、没成想、谁知道、冷不丁、闹了半天、原来、合着、敢情 | 依人物当前获知的信息表达意外或反应。人物对白、自己的心理可以“原来”，旁白不能借此替读者总结关系或真相。 |
| 强调、埋怨与轻重 | 还真、可真、都、就、好歹、至于吗、挺、怪……的、有点、实在 | 语气对应当下情绪与对象。强烈程度不能凭小词升级，“必须、得、偏要”会改变强硬程度，要符合人设。 |
| 商量、请求与打断 | 要不这样、你看、先别急、不是、等会儿、能不能、好不好、行了行了 | 让提议、试探、反问与制止带上真实口气；不固定给每轮配相同开头。打断、催促与逗弄依场景区分。 |
| 句尾语气与口语节奏 | 吧、呢、啊、呀、嘛、了，以及把……给……、腾出手来 | 依身份、年龄、成长环境、关系与情绪选择，保留语气和动作落点。“呀/啊”按本次口气选一个，不在正文写成候选串。 |
| 动作力度、幅度与速度 | 轻轻、稍微、慢慢、缓缓、猛地、急忙、一下、一点 | 动作确有相应特征，且当前值得注意；战斗与逃生的速度不能被修饰统一放慢。 |

这是选择方向，不是必用词表或固定替换库。句中“了、着、过”依完成、持续和经历自然使用；“还”也可以表达惊讶或程度，不只表示持续，“才”也可表达迟晚或程度，不凭词表将一种含义套到所有句子上。

### 把叙述里的动作与情绪接顺

承接人物正在做的事、刚听到的话和实际反应，写出动作怎样开始、接上、暂时停住或完成。适当保留“把……给……”“这才有空……”“……出手来”等口语节奏，动作顺序清楚之后，也可以用“还、仍、却、到底还是”延续本场情绪。连接与小修饰可以合用，不因一句中出现几个小词就自动删减。

以下是独立的原创示意，各有自身语境，不是本书事实或通用模板：

- **费了些口舌，接着处理来电：**她好不容易把人给劝住，这才有空腾出手来接电话。
- **话已到嘴边，却因眼前可见的状态收住：**话都到嘴边了，她看见他眼下的乌青，到底还是没说出来。这里写的是话没有说出口；若人物说了另一句话，要写出实际改说的内容，不能把“改口”和“没说出来”当作同一动作换词。
- **受到回应，原有局促尚未过去：**她把地址发了过去，手指却还停在屏幕上，等看见那边回了个“好”，才将手机揣回兜里。后续写实际反应，不由旁白宣布关系已确定。
- **前面确有等待，递手机也确实较慢：**他这才缓缓地把手机递了过去。
- **等对方腾出手：**她放下杯子，他这才把手机递了过去。
- **递手机后继续开门：**他把手机递过去，另一只手紧接着拉开了门。
- **两件事同时进行：**他把手机递过去，另一只手已经搭上了门把。
- **动作有可感知的延迟：**他把手机转向她，拇指还压着边缘，过了片刻才松开。不追加旁白认定他舍不得交出。
- **原句已自然，有力而无需展开：**他把手机递过去。

非视角人物只写当前可感知的行为。动作慢不自动等于不舍，动作快不自动等于愤怒；不能在承接后解释别人“其实”怎样想，也不能让视角人物看见本来背对他发生的微表情。

### 让节奏服从场景与人物

日常、暧昧、商量和需要消化情绪的场景，可以更充分地保留转折、商量、反问、小修饰及动作延续，让句内有起伏。人物嘴硬时可以一时磕绊，委屈时可以用“都、好歹、能不能”把当下口气说出来；具体分寸与原创台词见 [口语化与人物口气](colloquial-expression.md)，并与 [人物声线](character-voice.md) 的本场情绪和场景调整合用。

战斗、逃生和即时危险缩短无关谈话，仍可自然使用“再、先、快、了、跟着”等，使警告、请求与协同听起来是人在当场说的话。急迫不要求所有人变成生硬的口令骨架；专业命令、本人的有效短句与失语按真实人设保留。动作和即时后果继续承担主要推进，不在躲避攻击时展开长篇谈心。

公开、私下、陌生、亲密以及情绪强度会改变用词与说话分量。同一个人可以有不同口气，不把一套连接习惯、句尾成分或网络词覆盖全体人物。

### 分量、复现与时间关系

小词可以稍多，但同一处不机械叠加功能相同的连接或修饰。同一场景不反复用“紧接着”“这才”“缓缓”引出每个动作，也不把“接着、随后、随即”轮流替换成固定链条。保留自然反复的常用语法成分，不因前面用过一个“就”便禁止后文再用；需要避免的是显眼的习惯性堆叠、同义绕话与固定反应。

不得为使用某个词临时添伤势、误会、等待或无关事件。连接、动作与完成状态相互吻合：“另一只手紧接着已经拉开了门”可能使随后发生与此前完成的关系含混；递手机后才开门可写“另一只手紧接着拉开了门”。其他语境依实际时间判断，不将任何词组一律禁用。

补足口气不能改变本来发生的行为或人物立场。“行了行了，不逗你了”是停止逗弄，“行吧”可能是让步；“必须得我来选”比“我来选”更坚持。依真实语境采用，不把较长版本当成处处更好的替换公式。

## 减少重复用词与重复表达

同一场景、相邻段落和连续发言中，避免反复使用同一修饰词、动作词或引出台词的短语。尤其不要把“顿了一下”“微微”“轻轻”“缓缓”“不由得”等变成每段都有的习惯性填充。这些词可以在有具体作用时自然使用，避免重复不构成一律禁用；不要为避词删掉真实的轻重、速度与情绪承接。

前面已经写过“顿了一下”，后面不要无实际缘由再次使用。若没有新的停顿需要，直接接台词；若确有不同反应，写出导致停顿的眼前变化，或用当时正在发生的动作承接。不要依次换成“停了一瞬”“略一迟疑”“静了片刻”，却仍然给每句话加同样的停顿。

词语复现和语义复现都应节制：“目光沉了沉”“眼神暗了一分”“眸色变深”仍可能是同一种反应的重复。变化应来自新的刺激、选择或行为，不能只来自词典里的同义词。

人名、称呼、准确术语、物件名称、指定原话和有意回响可保持必要重复；不为避重随意换称谓、用含糊代词或把同一物件写成不同东西。人物确有依据的口头习惯可以保留，但不得每轮都重复。

## 不反复核对同一件事或身体情况

这个要求针对对白、动作与旁白，以及同一话题在相邻场景、章节中的重新展开。已经得到有效答复且含义被理解的内容，要成为后续行动的依据，不能每过几段又回到确认起点。

必要确认与情绪余波依 [回应速度与情绪消化](dialogue-craft.md#回应速度与情绪消化) 处理。允许有本场依据的失语、结巴、误解、改口及确认；人物得到澄清后仍可局促、难过或暂时说不下去。避免重复不能使人物迅速恢复冷静，情绪持续也不能成为连续索取同一保证或重做已完成身体确认的理由。

- 同一症状、伤处、疼痛程度、能否行动、是否吃饭或服药等已经明确后，不持续问“还疼吗”“真的没事吗”“确定能走吗”，也不换成相近问法继续索取同一回答。
- 同一任务、地点、条件、承诺或事件经过已经明确后，不反复复述、逐项重问或要求再保证。关心、焦虑、深情和谨慎不能成为重复核对的通用借口。
- 不用摸额头、看伤口、扶起试走、盯着脸色等动作变相重做已经完成的确认；不让旁白反复评估同一身体状态来填充段落。
- 多名已经知情的人不轮流问同一个问题。未获知此事的人可以按自己的信息范围询问必要内容，不能为了避重把他写成早已知情；传递已经交代过的信息时简洁处理，不重新演一遍完整核对。
- 必要确认须有未听清、理解偏差、突发信息明显超出当前预期等具体依据，对方针对性澄清后承接已理解的事实。身体情况再次询问必须有新症状、新信息、实际状态变化或原回答未解决关键问题的依据；只问新增或仍未明确的部分，不重新核对全部情况。不得为继续关心台词或延长情绪而临时制造症状、听错或疑点。
- 换地点、换章、时间略过或更换说话者，不自动让旧回答失效。依据适用阶段资料与正文接点接续，不重复已经确认的状态。
- 照顾可以继续，已知伤势也可以继续影响行动。通过递东西、调整行程、分担任务、配合步伐等实际选择展开，不能把减少核对写成伤势突然消失或人物停止关心。

独立示意：

不采用：“还疼吗？”“有一点。”“真的只有一点？”“嗯。”“走两步试试，确定没事？”随后又写他反复观察她的脸色。

可采用：她扶着桌沿慢慢坐下。“脚踝还疼，今天走不了远路。”他便把旁边的凳子挪了过来。“那你就留在这里吧，取货我去。先把清单给我就行。”

后续可以写取货、等待或两人实际配合，不无缘无故又问脚踝疼不疼。若后来发生新的摔倒、疼痛加重等真实变化，再围绕变化处理；这些只是允许重新询问的条件，不是每场必须安排的情节。

## 禁止套用模板化描写、形容和句式

禁止不分人物与场景就套用以下写法。遇到这些表达需求，从本场具体事实重新写，不通过更换一两个形容词继续保留同一模板。

- **泛化情绪替代具体反应：**“心中涌起一股复杂的情绪”“一抹难以言喻的情绪”“百感交集”。应写视角人物此刻想到、注意到或做出的具体反应。
- **惯用比喻自动套入：**不分情境就反复写“像一颗石子投入平静的湖面，泛起层层涟漪”“空气仿佛凝固了”“时间仿佛在这一刻停止”。禁的是机械套用，允许贴合本场人物、环境和实际反应的形容与比喻；具体写法见 [眼神、唇角与微表情](facial-expression.md)。比喻应对应可感知的特征，不能替代动作变化或泄露他人内心。
- **身体描写连成固定链条：**眸光一沉、喉结一滚、声音低哑、薄唇微抿轮番出现。任何动作都要有本场依据，不能复制整套反应给不同人物。
- **修饰词堆叠：**连续叠加“低沉、磁性、温柔、沙哑、带着不容置疑”等形容，或频繁用“微微”“轻轻”修饰一切。选择有意义的具体特征，不用辞藻数量冒充细腻。
- **机械转折与对称句：**把“不是……而是……”“没有……只有……”“仿佛……又仿佛……”接连用作旁白修辞骨架。禁止以固定句型替代真实叙述；人物需要否认或辨析时，应按其当前声线自然说话，而不是写成作者的对仗句。
- **结论式金句：**“这一刻她终于明白”“原来真正的……”“所谓……不过是……”“有些事情不必说，他们都懂”。禁止用这类句式替读者总结关系、真相或人生意义。
- **装饰性暧昧形容：**“不易察觉的”“意味深长的”“说不清道不明的”反复出现，却不给读者可感知的内容。该留白的动机保持留白，能写的动作清楚写出。

心理可以直接写，必要形容也可以用；表达要准确、贴合视角和语境。不要为了避开模板把句子写得生硬、故作朴素或换成另一套反复使用的固定句型。

## 对白前动作从当下情境里来

动作承接人物正在做的事，体现回应、犹豫、拒绝、靠近或退让。可以结合手、脚、眉毛、鼻子、步伐、姿势、呼吸以及物件和环境，但不按身体部位配额轮换。

| 情境与动作来源 | 可以怎样写 | 需要守住的边界 |
| --- | --- | --- |
| 手与物件 | 将杯子推回去、捏住纸角、松开门把手、把袋口重新折好 | 与物件位置及上一动作连贯，不凭空多出物件 |
| 脚与站位 | 收回迈出的脚、把椅子往后挪、从门口让开 | 符合人物坐立状态、距离和伤势 |
| 眉毛与面部 | 看见单据上的差额后拧眉、听清条件后扬眉 | 与具体刺激有关，不把“挑眉”写成所有人的固定反应 |
| 鼻子与环境 | 闻到烟味后掩鼻、冷风中鼻翼发红 | 视角能感知；不无缘无故写鼻部动作表达所有情绪 |
| 步伐与行动 | 放慢脚步等人、走到一半折回、侧身避开搬来的箱子 | 符合场景任务，不在急迫现场安排装饰性动作 |
| 当前事务 | 放下工具、翻到单据末页、按住将被风吹走的纸 | 行为服务本场交流，不让动作喧宾夺主 |

需要描写眼睛、泪水、嘴唇、唇角或面部细节时，按 [眼神、唇角与微表情](facial-expression.md) 选择本场有关的变化，并结合 [人物声线](character-voice.md) 决定显露程度。该文件统一承载具体方法、哭泣阶段、形容与比喻及原创示意，不在多个参考中重复列同一套例句。

对白前可以是一处明确的状态或动作，连续台词无需每次重新摆动作；优先保持交流流畅。当前视角只写可感知的行为与自己的感受，不从他人的表情或手势直接断定隐秘内心，也不在动作后附上作者解释“这说明他已经……”。

## 独立示意：同是接话，依据不同就写不同

以下为原创示意，不是固定话术，也不是一场必须拼在一起的对话。

- **手里正在整理材料：**她先将两张单据对齐，再用指腹压住多出来的那一项。“这笔是谁加的？”
- **准备离开又听见新信息：**他刚迈过门槛，听见那个地址，却又转了回来。“你确定是东仓？那边昨晚就封了。”
- **环境里出现异味：**她用袖口掩住鼻子，随即往门外让了半步。“先出去，这里有烟味。”
- **没有需要表现的新动作：**“东仓封了，就走南门。你把车牌发给我。”

最后一种可以直接说，不必为了变化再安排一次皱眉、停顿或抬手。一个动作承担足够作用就收住；对白的分量也由当前问题决定。
