# 眼神、唇角与微表情

本文件属于用词、句式与动作的细化参考。写作、扩写或润色需要面部反应时，只读取与本场有关的眼神、哭泣、唇角或组合段落；不为了用到本文件而给每轮对白新增表情。

先按 [人物声线](character-voice.md) 读取本书已匹配性格的当前情绪与场景调整，再合用 [表情的显露与收回](voice-context.md#表情的显露与收回)。本书人设、当前阶段、面对的对象、关系、情绪强度、现实环境和身体余力共同决定反应。表情是可采用的方向，不是情绪、性格或真心的识别公式。

## 写出表情怎样发生和变化

需要细写时，从本场实际刺激出发，选择有意义的形状、光泽、力度、速度或持续过程：眼尾怎样舒展，视线停在哪里，泪水怎样积起，唇线怎样松开，笑容怎样加深、被压住或消退。这些是选择维度，不是每次必须写全的步骤。

普通对答一处准确细节就够，关键情绪转折可以适量展开。原句已经准确、有力时可以保留“看向”“眼睛亮起来”或“嘴角弯起”；需要丰富时具体写出怎样亮、呈现什么质感、笑意怎样形成，不能反复只靠“猛地看向”“眼神一沉”“嘴角微微弯起”“嘴角慢慢抬起”覆盖不同人物和情绪。

面部各处可以配合：笑容展开时眼尾或脸颊跟着变化；忍哭时唇线绷紧，泪水仍积在眼睑上；怒气中眉间收紧，目光停住。只取当前真正能看见、有作用的部分，不每次把眼睛、眉毛、嘴唇、鼻翼逐项描一遍，也不以固定身体链条代替具体人物。

## 形容与比喻的选择

允许直接使用“眼神淡漠”“目光如炬”“眼底闪过狠戾”等贴合人物与本场反应的表达，也允许具体比喻。禁的是机械套用、过量堆叠与语义重复，不是禁止形容、修饰或文学性。

比喻应对应可感知的特点。例如星光可以呈现明快、细碎的亮，水光可以呈现清澈、湿润与晃动，火光可以呈现炽烈、骤起或压住未灭，霜与冷光可以呈现疏冷和锐利。它们不是专属情绪词表：眼睛亮也可能来自期待、求索或激动；泪光也可能与高兴、愤怒并存。

“像藏了星星”“像要喷出火来”可以依语境使用，并写出亮怎样随着笑意变化、怒气怎样从眉眼显露。不要每个笑都配星星、每次生气都配火、每个高冷人物都配刀锋。比喻的尺度、物象和词语应适合本书时代、叙述语言与当前视角的认识；不凭空添加实际灯光、伤势或事件来支撑一个比喻。

同一处表情通常取一个贴切的比喻就够；确有表达作用时可以扩展，不设必用数量或硬性配额。不要连续把眼睛比作星星、湖水、宝石，再堆上多组形容。先让读者看见实际变化，形容与比喻承担新增的质感。

## 眼神的形状、光泽与视线

下表全部为原创、彼此独立的示意，不是本书事实、固定词库或通用替换句。人物、物件和触发事件只属于各示例；实际写作从本书当前语境重新组织，不机械照抄。

| 情绪或状态 | 可参考的表达方向 | 原创示意 |
| --- | --- | --- |
| 开朗人物的惊喜 | 眸光晶亮、眼尾含笑、碎星般的光 | 她先是睁圆了眼，等看清盒子里的东西，眼尾便弯了下来，黑亮的瞳仁里像撒进了一把碎星。 |
| 兴奋、迫不及待 | 神采飞扬、目光灼灼 | 他整个人往前凑，眼睛亮得像刚擦着的火柴，盯住那张名单，连旁边的人叫他都没听见。 |
| 温柔、亲近 | 眼波柔和、眸光温润 | 她抬眼听他说话，眼尾舒展开来，目光像晒过太阳的浅水，清亮里带着暖意。 |
| 克制人物的高兴 | 眼尾松动、笑意藏在眼里 | 他仍旧抿着唇，眼尾却松了下来。再看向她时，那双惯常冷淡的眼睛里已经含了笑。 |
| 淡漠、疏离 | 目光淡漠、眼波不起 | 他的目光从她脸上掠过，平静得像一潭没有风吹过的水，很快便落回了手里的文件。 |
| 怒气外露 | 怒目、目光如火 | 她眉头一压，直直瞪住他，眼底像烧着两簇火：“你再说一遍。” |
| 压着怒气 | 目光森冷、眼神锐利 | 他没有提高声音，只把眼睛眯了些，目光冷得像刀背上的光，始终停在对方脸上。 |
| 狠戾、敌意 | 凶光骤现、目光狠厉 | 听见那个名字，他眼皮一掀，眼底骤然掠过一道凶光，像刀锋从暗处翻了出来。 |
| 羞怯、心虚 | 目光躲闪、眼睫低垂 | 她刚与他对上视线，眼睫便垂了下去，过了一会儿，又从睫毛底下悄悄看了他一眼。 |
| 疲惫、失神 | 目光涣散、眼神空茫 | 她盯着杯沿，眼珠许久没有动。窗外的车灯扫过来，又从那双眼睛里滑了过去。 |
| 坚定、专注 | 目光如炬、视线牢牢停住 | 她迎上他的视线，目光如炬：“名单上有我的名字，我会去。” |

前两行的兴奋程度、怒气的外露与压住，以及狠戾是否适合人物，都要由本书依据决定。不能把普通不满直接升级为凶光，也不能用一处湿润或发亮的眼睛确定他人的真实情绪。

## 哭泣的阶段与不同样子

哭泣可以发生在委屈、悲痛、愤怒、重逢、感动或喜悦中。先采用人物此刻的情绪与表达方式，再选择实际出现的阶段。下面不是必须依次完成的哭泣流程，不要求从忍泪一路写到哭肿。

| 阶段或处境 | 原创示意 |
| --- | --- |
| 委屈，却还在忍 | 她把眼睛睁得很大，下眼睑托着一层薄薄的水光，像一只已经盛满、却还没倾斜的杯子。 |
| 泪水逐渐积起来 | 眼眶沿着睫毛根一点点泛红，泪水漫上来，灯影碎在里面，随着她的眨眼轻轻晃动。 |
| 第一滴泪落下 | 她眨了一下眼，挂在下眼睑的泪珠终于滚下来，在脸颊上拖出一道细亮的痕。 |
| 无声地哭 | 她没有出声，只低着眼。睫毛被泪水黏成几绺，每抬一次眼，便又有一滴泪落下来。 |
| 哭得厉害 | 她眼睛已经哭肿了，睁一下便要用力眨回去；刚擦干的眼角很快又湿了，鼻翼随着抽噎一翕一翕。 |
| 想看清对方，却看不清 | 泪水糊住了视线，她接连眨了几次眼，他的脸仍像隔在一块被雨淋湿的玻璃后面。 |
| 哭过以后 | 她眼皮肿着，眼尾留下一片潮红。抬头时，湿重的睫毛慢慢分开，眼角还挂着没擦净的泪。 |
| 又哭又笑 | 她眼里还盛着泪，听见他那句话，却忽然笑了。眼尾一弯，积着的泪便沿着脸颊滚了下来。 |

忍哭不只有睁大眼，也可以闭眼、转身擦泪、说不下去或暂时不说。难过也可以无泪，表现为发怔、眼睛干涩、原有反应迟迟没有出现，或继续处理具体事务；不能让所有人受伤都红眼、所有悲痛都哭到失控。泪水不是情绪强度、真心或关系变化的证明。

眼皮红肿、睫毛湿重、持续抽噎等须符合已经发生的哭泣程度和时间，不刚落一滴泪就写哭肿。没有真实状态变化时，不每段重报眼眶、泪量或哭过后的身体情况。

泪水糊住视线、眼睛干涩等亲身感觉可由当前视角人物直接写；观察他人时只写能感知的外在部分，不能顺带知道对方看不清什么、为什么流泪或努力忍住的全部念头。

## 唇角、嘴唇与笑容的变化

不要把笑容全部简化成嘴角向上，也不要只轮换“微微弯起”“上扬了一下”“慢慢抬起”。可以写唇线松紧、抿住又松开、露齿、脸颊变化，以及笑容形成、加深、停住、收回、变僵或没有形成的过程。单侧抬起、冷笑等只在人物和语境支持时采用，不能成为所有人的默认笑容。

| 情绪或表情 | 原创示意 |
| --- | --- |
| 忍着笑 | 她把唇抿成一条线，脸颊却鼓了起来，最后还是从唇缝里漏出一声笑。 |
| 笑容越来越明显 | 他起初只露出一点笑，听她越说越认真，笑容便逐渐展开，连眼尾也起了细纹。 |
| 笑得灿烂 | 她笑得露出一排牙，脸颊向上鼓起，眼睛跟着弯了，像整张脸都迎着太阳舒展开来。 |
| 得意，又想装作平常 | 她抿了抿唇，刚压下去的笑又从一侧唇角冒出来：“也没有很难吧。” |
| 羞涩、被逗笑 | 她低下头，唇边的笑藏进了围巾里，只露出一小截泛红的脸颊。 |
| 温和、安抚 | 他唇边的线条松下来，露出一个舒缓的笑，往旁边挪了挪，给她让出位置。 |
| 勉强维持笑容 | 她牵了牵嘴角，笑容却绷在脸上，连说话时都没能自然地松开。 |
| 笑容突然消失 | 他的话才说了一半，她唇边的笑便停住了，随后一点点收回去，露出的牙齿也被合拢的嘴唇遮住。 |
| 讥讽、轻蔑 | 他只有一侧唇角挑了起来，眼睛却冷冷地看着对方：“这就是你的解释？” |
| 委屈得说不出话 | 她张了张嘴，下唇先颤了一下，随即被她紧紧抿住，刚要说的话也没了声音。 |
| 想笑，却要哭 | 她试着朝他笑，嘴角才牵起来，下唇便抖了，最后只挤出一个短促的气音。 |

人物可以笑着流泪、怒中抿唇、因紧张而露出不自然的笑；同一表情有不同原因。后续由对方实际回应和新的刺激决定，不在每次笑后补“他心里已经……”或“她其实是在……”。

## 组合、节奏与心理留白

写作时让本场刺激、表情、台词和行动自然相接，顺序可以随语境变化，不固定成“先抬眼，再抿唇，再说话”。必要的“等……”“这才”“却”“仍”等成分以及速度、力度修饰，采用 [连接词、语气成分与小修饰词](expression-craft.md#连接词语气成分与小修饰词)，不把所有表情都放慢或写成逐帧镜头。

日常与暧昧可适量展开笑容和目光的变化；争执可取笑容收住、唇线绷紧或目光停住的转折；重大失去依实际余力选择哭泣、失语或无泪反应；战斗只取当前视角来得及察觉、对行动有用的细节。普通对答不每句配表情，人物已有情绪也不每段重复同一套形容与比喻。

全书遵守 [视角、心理与留白](perspective-restraint.md)，同一连续场景只直接展开一位主要人物的心理。可以呈现他人当前可感知的样子，不能从眼神或唇角确认爱意、悔意、欺骗、秘密决定或未来行动；有依据的猜测明确属于本人，并保留不确定。本场其他人物也可以观察心理主角的微表情和微动作，按自己的性格、情绪与处境皱眉、停下动作、移开视线或改变说话方式；其未说出口的判断通过可见反应留白，旁白不直接揭晓猜中了什么。

如果当前视角没有看见、听见或通过其他有效途径获知，就不能写“在他没看见的时候，她嘴角上扬了一下”等隐藏表情。若她是当前视角人物，可以写她自己的动作或唇边实际感受；若他是当前视角人物，就只写他实际能感知的部分，不能借微表情切入场外镜头。

表情已传递出的情绪分量交给读者感受，不补“这说明她已经原谅他”“他终于学会爱人”等解释、关系定性或升华总结。微表情同样不改变全书对白优先、场景主次、简洁台词与完整章节留具体钩子的规则。
