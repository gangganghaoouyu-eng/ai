# 章末具体钩子与禁止升华总结

## 完整章节的收束要求

完整连载章节完成本章承诺的核心场景后，章末必须留下具体牵引，让读者能够指出接下来尚待发生、回应、选择或弄清的事。钩子来自本书大纲、已有线索和本章真实变化，不为每章惊险临时添新反派、事故或重大秘密。

本章可以完成一次和解、一项事务或一段温暖相处，再落到已经提出的邀请、将要执行的安排或还未给出的回答。情绪余韵本身不能替代具体牵引，也不需要为了留钩子破坏已完成的温暖场景。

短片段、节选或局部润色不强加完整章末结构。明确要求全书终章或彻底闭合的结局时，以用户的终局要求为准，不另开无依据的新主线。

## 按本章实际内容选择牵引

| 钩子方向 | 落点 | 使用边界 |
| --- | --- | --- |
| 待执行的决定 | 人物已经商量的下一步、出发前的新条件、即将兑现的承诺。 | 有明确对象或事项，不能只写“明天会更好”。 |
| 尚待回应的请求 | 一项邀请、合作条件、必须作出的选择。 | 先充分呈现请求与处境，不靠无缘由拖延答案。 |
| 新发现或信息矛盾 | 当前视角实际看到、听到或收到的细节，与已知事实产生联系。 | 不提前解释全部答案，不偷渡场外真相。 |
| 行动的具体后果 | 刚才选择导致的现实改变、损耗、限制或新任务。 | 因果有依据，不能突然凭空惩罚人物。 |
| 关系中的下一步 | 已提出的见面、尚待决定的同行、交付物件后需要回应的安排。 | 不由旁白宣布关系升级；日常、温暖章也可以采用。 |
| 旧事或伏笔的回响 | 已存在的原话、物件、痕迹或约定在当下出现新的语境。 | 回读旧资料后使用，不捏造前文，不把回响当作结论。 |
| 尚在持续的现场事件 | 确有依据的敲门、通信、逼近的行动或正在发生的异常。 | 只能写当前视角可感知的部分，不每章机械套敲门或电话。 |

一次结尾通常收在最有分量的那项牵引上，不连续堆出几个事故、秘密和威胁。钩子不一定是悬疑，也不要求每章新增伏笔。

## 不采用的结尾

- 不写“他们终于懂得了爱的意义”“这就是信任”“平凡才是幸福”等升华、道理和人生金句。
- 不补“这一刻两人的距离终于更近”“她已经重新相信了他”等作者替读者定性的总结。
- 不写“真正的危险才刚刚开始”“命运的齿轮悄然转动”“她还不知道……”等全知警告或空泛未来预告。
- 不切到未经授权的敌人内心、远处阴谋或未来场景制造悬念。
- 不在正文之后解释“这个钩子为下章埋下伏笔”，不加下章剧情摘要。
- 不在本章承诺的核心事件尚未展开时，靠截断一句话或刚要揭晓就结束来拖欠内容。
- 不把已经得到有效答案的问题重新写成未解，不用反复核对身体情况充当牵引。

## 落在人物当下能够感知的事上

可用一句台词、动作、物件变化或收到的信息结束，不必最后再添加说明。最后一句继续符合说话者的人设、情绪与知情范围，不能让人物忽然替作者预告主线。

独立示意，仅用于说明边界，不是固定话术：

不采用：她把备用钥匙递给他，两人终于明白了信任的意义，而真正的考验才刚刚开始。

可采用：她把备用钥匙放到他手边，指尖还压着钥匙圈。“明早去旧仓库，你愿意陪我吗？”

后一种写法以具体邀请留下待回应的事；是否适用于本书，仍取决于已有旧仓库安排和当前关系。普通场景结束不必都承担章末钩子，完整章节结束才执行本文件。
