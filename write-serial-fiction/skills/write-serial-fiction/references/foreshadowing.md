# 伏笔、延续与旧事回响

本文件指导正文中的线索分量和表达时机，不建立伏笔档案，也不要求每章新增伏笔。以本书章纲、卷纲、既有正文和阶段资料为依据。

## 先知道本次要做什么

区分埋设新线索、延续未解线索、部分揭示、正式回收和情感回响。大纲安排的未来答案仅供作者控制写法，不得自动进入人物的当下认知。

涉及之前的伏笔或旧事时，先按 [既有小说资料读取规则](source-reading.md) 回读对应旧阶段文件。需要精确特征、原话、位置或谁接触过时，再读相关旧正文。不能根据当前想要的答案反向捏造前文。

## 埋设时让细节属于眼前场景

线索可以是物件、缺漏、说法矛盾、异常行为、习惯、环境痕迹或未完成的安排。出现时应有可信的当下用途或被注意的理由，不能像作者额外摆上的谜题。

视角人物可以注意、误解、暂时略过或提出疑问；具体程度依据其知识和现场状态。不加“她还不知道这有多重要”“日后才会明白”等提示，不为每个细节加重语气。

服务当前场景的轻微暗示可以合理补充。决定重大真相、反派身份、世界规则、人物身世或关系转折的新伏笔必须有已有计划或明确授权；无依据时不另开主线。

## 延续与部分揭示

让再次出现带来新的语境、差异、后果或人物回应，避免重复同一疑点凑悬念。人物只有获得新依据，才有理由改变判断。

部分揭示可以回答一个问题并留下另一个具体问题，但不能不断拖延本章已承诺的答案。章纲还未允许揭示的真相保持隐藏，不由全知旁白提前确认。

## 回收靠当下证据与行动

回收时承接前文已有细节，通过发现、辨认、交涉、选择或事件后果把联系呈现出来。视角人物在证据充分时可以明确推断，关键真相应让读者看懂；无需在其后追加作者式“原来一切早有安排”。

参与过旧事件的人与后来才得知的人，对线索的反应应不同。已经回收的伏笔不重新写成无人知晓，已经公开的秘密不倒退成悬念，尚未被某人物得知的答案也不因读者知道就让他知道。

旧资料存在空缺时，不宣称前文已埋下某个精确细节。可以使用确有依据的联系；缺失部分决定重大回收结果时询问必要信息。

## 情感回响保留变化与留白

旧台词、地点、动作或物件再次出现，可以因为人物当前的选择而产生不同分量。不必原句重抄，精确引用时保留已知原话，不把尚未修复的关系写成完全恢复。

独立示意：前文人物总把钥匙留在门外，当前场景中第一次带走了它，可以让另一人停下手里的动作或重新安排等候。是否意味着离开、试探或只是另有事情，应由本书事实与后续展开决定，不在旁白里替读者选答案。

完整连载章节按 [章末钩子与收束](chapter-hooks.md) 留具体牵引，可以落在一处实际变化或仍待回应的问题上。钩子不等于每章新增伏笔，不强行每章惊吓，不把伏笔写成下章预告，不在结尾升华总结或切到全知视角解释。
