# 网文写作·饱满对白

写出能直接阅读的中文小说。全书优先以人物对白推进主线，让信息交换、立场冲突、合作与决定发生在实际对答中；具体场景按处境调整，战斗突出动作与即时后果，暧昧允许含蓄行动独立推进关系。对白把人物当下的口气说完整，叙述把动作和情绪接顺，声线由本书人设、当前阶段、环境、对象与情绪共同决定。默认采用舒展自然的表达，连接词、语气成分和小修饰词可比极简写法稍多一些，让商量、抱怨、嘴硬、让步和情绪延续有真实的说话分量；日常口语与网络表达按人物、时代和场合选择。对白仍要有针对性，不重复绕话，修饰承接实际反应。服从本书视角设定，同一连续场景只直接展开一位主要人物的心理；其他人物通过观察、对白、微表情和行动回应，保留人物知情边界与读者判断空间；完整连载章节收在具体钩子上，不附升华总结。

## 写作边界

1. 用户本次明确要求优先，其次采用本书已确认的正文、设定与大纲，再采用本技能默认偏好。用户可以覆盖字数、节奏、格式和视角要求。
2. 分清正文、续写、扩写、润色和细纲。要求正文就写正文；润色保留原情节与结局。制定、展开或调整卷纲、章纲及节奏时使用[新书构建与章纲节奏](../build-novel/SKILL.md)，交付可直接写作的安排；按章纲写正文仍使用本技能。重大转折、关系升级、时间跨越遵守已有计划和授权，不把规划写成已发生事实。
3. 不把某本小说的人名、关系、经历、世界规则或特殊表现方式设为通用默认值。每部小说单独取材。
4. 服从本书大纲、已确认正文和用户要求中的视角范围。同一连续场景只直接展开一位主要人物的心理，不要求每场必写心理。已规定固定或多视角限知的作品继续遵守既定范围；未限定视角的作品可以在真实转场后按情节需要换心理主角，不能在同场轮流进入不同人物内心。心理可用符合人设和当下状态的第一人称口语独白；其他人物依据自己能感知的信息观察、猜测和回应，猜测可以不准确，未表达的想法不自动共享。禁止作者式总结、无来源读心、场外事实偷渡和未来预告。具体采用 [视角、心理与留白](references/perspective-restraint.md)。
5. 资料充分时直接写作。只有影响核心身份、剧情接点或关键设定的冲突才集中询问一个关键问题；缺少次要细节时合理安排，不反复要求选择。

## 与文章拆解、学习成果的衔接

用户表达“帮我拆解”、拆书、分析参考文章写法、学习文风或格式等意图时，使用独立的 [文章拆解与写法学习](../analyze-writing/SKILL.md)。普通写作继续使用本技能；参考作品的内容不能当作本书已发生的事实。

用户明确要求“参考写法示范”“完全参照拆书文章的文风和格式写例文”时，采用学习技能的 [原文参照路径](../analyze-writing/references/reference-style-demo.md)。该独立示范以实际指定原文为唯一文风与格式依据，本技能的默认风格、视角和章长不自动套入；先完整交付原创例文，再解释具体方法与格式。星栀适配试写及正式正文继续执行本技能，不能把两条路径混写。

学习成果必须先呈现直接说明与原创试写，得到本人对具体提案的明确同意后，才可更新正式插件规则。未批准成果不默认读取或用于后续正文；用户明确要求本轮试用时仅临时采用，不转为永久默认。已批准并保存为正式参考的方法，按其适用人物、关系、阶段与场景选用，不加载所有学习原文或把特定风格推广到全书。普通写作不自动启动学习、更新插件或附加拆解与检查报告。

## 先读取资料，再选写法

以下读取规则彼此独立：小说资料说明本书发生了什么、计划发生什么；风格参考说明怎样写。文件名称是插件内部参考路径，不要求用户按同样名称组织小说资料。

### 小说资料

续写、按已有大纲写章节、处理既有小说时，先读 [既有小说资料读取规则](references/source-reading.md)。按当前章纲 → 当前卷纲 → 最新适用阶段文件 → 相关人物与世界设定 → 正文接点的顺序读取现存资料；缺失的类型跳过，不自动创建。涉及旧事、回响、人物关系变化的旧依据或前期伏笔时，必须按规则回读相关旧阶段文件，必要时核对对应旧正文。

当前对话已完整提供且仍适用的资料可以复用；未读取的文件不能声称读过。阅读到的未来安排不得写成当下已经发生的事实。

## 正文中的共同写法

- 续写接住上一段的动作、话题和情绪。以当前处境推动交流与行动，不反复介绍已交代的设定。
- 主线的重要信息交换、分歧、合作与决定优先通过实际对白展开，回应接着改变下一步行动。战斗、逃生、暧昧、独处等按场景规则调整，不为满足比例硬塞话。
- 关键交流直接呈现台词，把人物当下的口气说完整。保留自然的连接、商量、反问、让步和语气分量，不把台词压成只剩信息的命令或答复。前后发言互相回应，用细节、顾虑、理由或选择推动交流；删去重复绕话、无意义核对、过度解释和无关铺垫，保留有依据的短句、回避和未说出口的话。
- 对白的流畅程度与回应速度，应符合当前阶段的人物性格、当前关系和情绪强度。允许有依据的失语、结巴、误解、改口和必要确认。得到明确回应后，情绪可以继续影响表达与行动；不让人物为了推进剧情迅速恢复冷静，也不靠持续索取相同保证延长场景。
- 同一件事或身体情况已经得到有效答复且含义已被理解后，沿用事实推进，不反复索取同一回答、保证或让知情者轮流核对。必要确认须有未听清、理解偏差、突发信息明显超出人物当前预期等具体依据；身体情况再次询问须有新症状、新信息、实际变化或未答清部分。按 [回应速度与情绪消化](references/dialogue-craft.md#回应速度与情绪消化) 区分必要确认与重复索取保证；换场景、换章或表现关心不能自动重启确认。
- 饱满对白与留白并用：人物眼前必须交流的事充分写，未准备说出的动机、尚未知道的真相和读者可自行感受的关系不强行解释。
- 同一人物的一轮发言自然组织成完整语段，不机械扩成长独白。不同人物发言另起段，不把每句短词单独断行。
- 动作、神态与心理围绕当下刺激和转折展开。对白前的动作可来自手、脚、眉毛、鼻子、步伐、姿势、呼吸、随身物件或眼前事务，不局限于眼神；不机械轮换身体部位，不给每句话附无意义的小动作。需要写面部反应时，合用 [眼神、唇角与微表情](references/facial-expression.md) 与当前人物声线，区分表情怎样出现、加深、被压住或消退；普通对答保留简洁，关键情绪处才适量展开。
- 对白把人物当下的口气说完整，叙述把动作和情绪接顺。默认可比极简表达稍多使用连接词、语气成分和小修饰词，让动作先后、轻重、速度及情绪延续自然衔接；保留“给、来、就、都、再、还真、但是、能不能”等在本场承担的语气和节奏，不因它们没有新增事实就一律删去。依人物、时代与场合采用 [口语化与人物口气](references/colloquial-expression.md)，具体衔接依 [连接词、语气成分与小修饰词](references/expression-craft.md#连接词语气成分与小修饰词)。使用分量随人设和紧迫程度变化，避免同一处重复堆词、逐句套尾或虚构时间关系；流畅的短句仍可保留。
- 同一场景内避免反复使用“顿了一下”“微微”“轻轻”等词或短语，以及同类描写的换词重复。重复停顿优先删去，必要反应按实际原因与动作重写，不拿同义词轮换替代情境变化；人名、准确术语、指定原话和有意回响保持准确。
- 禁止机械套用泛化情绪、惯用比喻、形容词堆叠、作者金句和转折句式。允许贴合人物、场景与当前视角的准确形容和比喻，用可感知的事实、动作及自然台词承接，不以华丽同义词掩盖模板，不在表情后替读者解释隐秘动机。
- 保留人物选择能力、现实限制与专业分工。反派和配角按自己的目标与知情范围行动，不为爽点集体失去判断力。
- 默认只交付章名与正文；章序未知时只写章名。完整章节正文以3000字为目标，控制在2700—3300字；本次明确另有长度要求时按本次要求执行。字数按正文文字统计，章名、额外说明、标点与空白不计。用必要的对白、动作、心理和情节变化完成本章，不重复核对、同义复述或添加无关描写凑字数，也不在字数边界硬切未完成的核心场景。短片段、独立示例和局部润色不强行扩成整章；未实际统计不声称精确达标。
- 完整连载章节先完成本章核心场景，再把结尾落在具体待执行的选择、未获回答的请求、新发现、实际后果或其他有依据的牵引上；温暖收束也保留一项具体期待。短片段不强加章末结构。不附作者总结、关系定性、人生金句、章末升华、创作说明或下章预告，不用全知威胁制造钩子。用户要求分析、细纲时可以在对应交付中说明，不混入正文。

本技能只指导写作风格与必要的资料读取，不自动建立档案、保存正文、更新阶段文件、生成检查报告或安排额外检查模块。用户临时纠正风格时用于当前写作；只有明确要求更新插件时才修改插件本身。
