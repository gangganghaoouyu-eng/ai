# 学习成果、候选规则与原创试写

## 分类与状态

内容类型和批准状态分别记录，不能用“通用方法”这个名称暗示已经获准。

| 内容类型 | 判定与使用 |
| --- | --- |
| 通用写作方法候选 | 在已读多个情境中有依据，且通过相应原创试写展示。仍须说明限制；一次试写不足以证明普遍有效。 |
| 特定风格与场景技巧 | 为某种人物、关系、叙述声线或场景服务。保留调用条件，不能覆盖所有章节。 |
| 待验证发现 | 目前只有局部样本、未读够前后文或效果未明。写清疑问、反例及下一次可验证的方向，不升为正式规则。 |

每条成果按实际情况标为“待验证”“已试写、待本人批准”“已获批准、待写入”“已写入正式参考”或“已否决／已被替代”。用户明确只要分析、不做试写时标记未试写；模型自评通过不得自行升为已获批准。状态缺失或来源不明的旧记录不能直接作为已批准规则使用。

## 记录一条成果

有实际价值的发现才形成记录，不规定每次必须产出几条。重要候选包含：

- 编号、记录版本、分析日期与内容类型。
- 作品及作者（已知才填）、链接或文件、章节或段落定位，以及实际阅读范围、缺章和来源差异。
- 观察尺度与角度：句段、章节或跨章阶段，属于开篇、人设、节奏、闭环、结构、文风格式或原创迁移。章次、间隔、金额口径与首次回收等结论保留可复核依据；未读到的部分不填成已确认。
- 具体写法与效果依据；哪些是原文事实，哪些是当前分析或推测。
- 可执行的方法、适用人物与场景、限制及失效情况。
- 对照的现有规则位置与实际内容；关系标为已覆盖、可补充、可合并、需替换、需缩小范围、冲突不采用或证据不足。
- 拟调整的位置、操作与完整候选文字；涉及修改或删减时写清原规则与改后文本，不只写“优化对白”。
- 原创试写的路径（参考写法示范或星栀适配）、实际采用的方法、效果与尚待验证之处，以及用户反馈；参考模式记录原文文风和格式依据、例文对应处及与正式规则的差异。
- 批准状态；如已获批准，记录本人同意的范围与对应提案版本。实际写入后才记录插件版本与保存结果，不能提前填写。
- 如替代旧成果，保留旧记录的来源和版本依据；便于撤回效果不好的改动。

没有插件编辑工具或无法读取当前规则时，可以提炼和试写，但对照结论要标明未核实，不能凭旧记忆声称已经检查当前版本，也不能声称已写入。

## 原创试写

默认学习任务同时提供直接说明和原创正文试写，让用户能判断方法是否适合自己的作品。先确定参考写法示范或星栀适配路径：明确要求完全参照文章时，读取 [参考写法示范](reference-style-demo.md)，以实际指定原文为唯一文风与格式依据，先完整原创例文，再对应原文和例文说明具体方法及格式。没有该要求时采用星栀适配试写；要求比较时分别标明规则。选取主要且值得展示的发现形成连贯片段，不按每条记录硬凑一段。

开篇、节奏、闭环、升级或结构方法可以先给简要原创剧情方案、章节安排或阶段变化，指出目标、压力、准备、回报与后续承接；再试写其中关键场景，说明该片段展示哪一环、哪些长期效果仍不能由短片段验证。脑洞提案与正文试写互相配合，不能只列方案就宣称完成了试写。只有本轮明确排除试写时才省略，并保持未试写状态。

用户给出原创人物、阶段或场景时，沿用已确认资料；涉及既有小说，依 [小说资料读取规则](../../write-serial-fiction/references/source-reading.md) 读取实际有关的章纲、卷纲、阶段和接点。不能替用户新增重大剧情、人设、关系升级或未来既成事实。只有想看写法、没有小说资料时，可使用简短、明确标为独立示意的新人物和新场景，不将它们存成本书设定。

两条路径均用原创内容展示，不复写参考情节；参考示范的风格、格式与长度依其专门规则，不由下述适配要求覆盖。星栀适配试写把本场人设、情绪、对象、环境与知情范围合用；保留口气完整、动作和情绪接顺、适度增加连接和小修饰的当前偏好。战斗、暧昧、独处等按现有场景主次安排。服从本书视角范围、同场只直接展开一位主要人物的心理、人物知情边界、留白、不替读者总结和禁止章末升华继续适用；心理可以采用符合人设的第一人称口语独白。片段不硬加整章钩子或扩到整章字数，完整章才执行2700—3300字正文目标及完整章节的收束要求。

进行星栀适配前后对比时，使用同一原创情境的“现有写法”和“采用候选方法后”的版本，保持人物、事件、视角和信息相同，改变与学习发现有关的表达。现有版本应正常写，不故意写差来制造进步，也不把局部更顺当作整章质量已经提高。比较参考示范与星栀适配时保持核心原创事件可比，允许视角、句段和收束依各路径发生对应变化，并说明差异，不要求两版使用相同视角。

试写之后直接说明：用了哪些方法、具体落在哪些句子或动作、何处改变了口气或节奏、哪些地方仍需用户判断。允许发现试写不适配，从而缩小条件、改写或放弃候选。不能仅用“更有活人感”评价全部效果，不能承诺每次学习必然提升。

## 小说拆解的呈现

先说明阅读范围和核心观察，再按七个角度呈现本次有证据的部分。结合 [小说故事机制](book-analysis.md) 的对应表格：开篇有节点与接续，人设有表达与选择，节奏有每章变化及升级，闭环有压抑到兑现，结构有阶段与关键转折，文风有句段依据，迁移有原创变化。表格说明不同问题，不重复粘贴情节摘要。

全书分析可逐批交付已读章节进展、局部闭环和暂定阶段，在相关前后文读齐后修订全书判断；每批注明覆盖范围，不能跳过未读部分或把抽样分析标为全书完成。只有节选时，简要列未覆盖角度及具体缺失，不强行索要全书，也不把缺失角度写成长段空话。

涉及“第一处”“每隔多久”“整部作品都如此”等结论，限定证据范围；推断潜在读者效果与真实数据结论分开。原创创新方案标明新创作，不能与原作情节或本人本书既定事实混列。

## 交付与积累

以用户容易审阅的方式组织：实际阅读范围；具体拆解；学习成果与适用条件；现有规则对照；原创试写与解释；拟写入的具体文字、位置和当前状态。长篇可分批，优先交付用户本次关心的部分。已明确排除某项时遵守本次范围，但未经展示和同意的成果不成为插件默认规则。

记录可在用户指定或已确认的插件包外学习目录积累，原文保留来源，方法保留定位与摘要，写作时主要读取已批准的适用方法。没有合适的已确认存放位置时先在对话中交付；本轮没有保存就明说尚未保存，不宣称已经建立长期记忆。

普通写作不自动读取所有原文与待批准记录，不重新附加拆解报告。如何获得同意与整合规则见 [本人同意与规则整合](approval-and-integration.md)。
