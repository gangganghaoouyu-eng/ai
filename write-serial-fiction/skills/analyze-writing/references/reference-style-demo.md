# 完全参照实际原文的写法示范

在用户要求“参考写法示范”“完全参照这篇”“按原文文风和格式写例文”等情况下采用本文件。以实际读取、明确指定的文章或章段作为本次示范的唯一文风与格式依据，使用原创角色、事件和台词展示；不混入其他作品、模型惯用写法或星栀默认风格。

## 读取与范围

先读实际原文并确认样本版本、章段或段落边界。用户已经指定对象时直接读取；不能仅依据书名、作者印象、简介或拆解摘要写例文。无法读取原文时说明缺失并请求对应原文，不能用通用样文冒充参照结果。

用户指定整篇时按完整范围读取；长篇可分批，并说明本次实际参照哪些连续章段。节选仅支持节选特点；不声称已掌握全书风格。区分真正段落与屏幕自动折行，排版提取有缺失时标明受影响的格式，不编造原有空行或标点。

## 建立原文写法与格式依据

按实际存在的特征记录原文定位、具体习惯及示范使用方式。没有材料支持的维度标为未展示，不硬补一整套画像。

| 维度 | 观察并参照什么 |
| --- | --- |
| 人称与视角 | 叙述距离、限知或全知、心理归属、信息进入方式及真实转场 |
| 句式与口气 | 长短句组合、连接与语气成分、重复或省略、语体与叙述声线 |
| 对白与回应 | 一轮发言的组织、回应方式、说话者标识、信息及冲突怎样推进 |
| 动作与心理 | 动作落在对白前中后的位置、心理怎样进入、叙述与台词的分工 |
| 描写与修辞 | 环境、感官、表情、修饰与比喻的使用分量及作用 |
| 分段与标点 | 真正的段落边界、换人换段、同轮台词是否拆开、停顿与独白标识 |
| 场景与收束 | 开场入口、场景压缩与展开、转场、结尾落点及章间响应 |

完整参照指本次例文中各项文风和格式决定都有所读原文依据，保持样本可观察的组织习惯。不要仅抓一个标签或口头禅就声称完成，也不以“参考”之名写回星栀默认样式。新情境的句段按真实因果组织，不逐句替换人名重写原段、拼接原句或复刻标志性情节；所展示的是方法与格式，原文短引文与原创例文分别标识。

## 独立示范的规则优先级

本轮明确要求 → 指定原文的实际文风与格式 → 新例文必要的内容连贯。星栀正文的默认对白偏好、连接分量、分段方式、同场单一心理主角、留白、禁止总结式收束及2700—3300字章长，不自动约束这条独立示范路径。

原文实际采用短碎句、长叙述段、全知、同场多人物心理或总结式结尾时，在独立例文中按对应依据呈现，并在随后说明中定位这些方法；原文没有采用则不自行加入。不要先按星栀写一版，再替换少量词语冒充完整参照。

未指定原创人物时使用独立新人物和情境。使用本人既有小说人物时先读取有关设定；保持核心身份、已发生事实与当前关系。用户同时要求该书固定视角或其他不可变条件时遵守明确条件，说明相应参照范围受到何种限制；必要时另用独立情境展示冲突特征，不能谎称两种冲突要求都已完全满足。示范内容不自动成为本书正文或已发生事实。

本路径只是当次学习示范，不自动改变星栀的正式写法，也不赋予后续正文永久采用该样本的授权。

## 先例文，后具体说明

交付顺序：
1. 简要说明本次原文范围及可复核的主要特点。
2. 完整交付连续的原创例文，按样本文风与格式写，不在例文中插入讲解。长度服务要展示的特征；未覆盖整章时不冒充章间节奏已经验证。
3. 再解释具体写作方法与格式，将每项联系到原文定位和例文段落。说明怎么操作、产生什么阅读效果、依赖什么前提；格式写清换段、同轮台词组织、动作位置、心理标识、标点及收束等实际规则。
4. 对原文有而例文尚未展示的特点列出限制或补足示范；不能自行宣称百分之百相同或已验证所有尺度。用户要求对比时，再提供星栀适配版，并明确两种路径采用的规则。

说明可使用“原文位置／观察到的方法或格式／例文对应处／操作与适用条件”的表格，不以“高级、有生活感、节奏好”等泛评代替步骤。不把局部词频、段长或比例设置成所有作品的配额。

## 方法进入章纲或正式规则

表达方法进入有关写作参考，跨章冲突、信息和回报安排可交给 [章纲与节奏](../../build-novel/SKILL.md) 形成独立原创方案。短例文只能验证已展示的局部，长期铺垫、升级与兑现需更长样本及反馈。

按 [学习成果](learning-results.md) 记录来源范围、示范路径、具体方法、适用条件、原文与星栀规则差异，以及待验证部分。按 [本人同意与整合](approval-and-integration.md) 获准后再更新正式规则；同意观看示范、满意或临时试用不等于永久写入。整合可以补充、合并、替换、删减或放宽，不能把参考作品的一整套特点自动设为所有小说默认。
