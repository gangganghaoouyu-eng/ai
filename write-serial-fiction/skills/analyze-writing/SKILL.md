# 文章拆解与写法学习

研究实际原文怎样建立期待、推动情节、立住人物并兑现回报，解释表达与格式怎样产生效果；用有来源、有适用条件的原创示范展示所得。根据真实反馈改善规则，不自行后台搜书、持续更新或将一次阅读当成永久学习。

## 输入与路径选择

优先读取本次正文、附件、文件、链接及明确指定的作品范围。对象能够确定时直接读取；既无对象也无正文时集中询问参考对象。书名、简介、评论及搜索摘要不能替代原文，遵守 [读取、证据与表达拆解](references/analysis-method.md)。

| 请求 | 采用的路径 |
| --- | --- |
| 拆书、分析写法、提炼并试用星栀方法 | 按实际范围分析，默认提供学习说明与星栀适配试写 |
| 参考写法示范、完全参照原文、照文章的文风和格式写例文、模仿所读文章写法 | 读取 [完全参照原文的示范](references/reference-style-demo.md)，以指定实际原文为唯一文风与格式依据写原创例文 |
| 比较参考写法与星栀写法 | 分别呈现参考示范与适配版，标明采用规则及对应差异 |
| 仅剧情简介、仅分析或明确不试写 | 按本次范围交付，缺少试写的成果继续标为未试写、未批准 |
| 构建新书、制定或调整本人小说章纲、卷纲及节奏 | 使用 [新书构建与章纲节奏](../build-novel/SKILL.md) |
| 普通创作、续写、扩写或润色正文 | 使用 [小说正文](../write-serial-fiction/SKILL.md) |

明确指定的路径优先，不把“完全参照原文”改成星栀适配试写。用户指定了原创场景就沿用获准事实；没有场景时用独立原创情境，不把参考人物或事件带入本人小说。

## 阅读范围与七个分析角度

先报告实际覆盖，再展开有证据的部分。完整作品或指定阶段按有关角度覆盖；只有节选时说明其余角度缺什么材料，不编造开篇、全书节奏或回收章次。用户指定重点时优先重点。

| 角度 | 要解释的问题 | 参考 |
| --- | --- | --- |
| 开篇 | 前三章如何留下读者，转机、核心冲突、初次回报和章末接续在哪里 | [故事机制](references/book-analysis.md) |
| 人设 | 主角、群像及配角怎样通过语言、动作、心理和选择立住，阶段怎样变化 | 故事机制、表达拆解 |
| 节奏 | 每章改变什么，冲突、过渡、爽点和升级如何安排，钩子怎样响应 | 故事机制 |
| 闭环 | 一轮压力、准备、爆发、兑现和收尾怎样形成，产生什么实际后果 | 故事机制 |
| 结构 | 阶段边界、目标、困境、对手、关键转折及身份变化，伏笔何时起作用 | 故事机制 |
| 文风格式 | 对白、句式、口气、动作、心理、视角、分段、标点及结尾怎样服务剧情 | 表达拆解；参考示范时另读示范规则 |
| 举一反三 | 改变目标、关系、资源、代价、顺序或信息怎样形成原创方案 | [原创变化](references/creative-transfer.md) |

句段解释表达，相邻章节解释承接，跨章阶段解释升级与结构。不能用一处有力台词代替整轮冲突分析，也不能用阶段概述省掉文风与格式依据。

## 分析、示范与提案

1. **读取并定范围。**记录版本、实际章序、缺章及覆盖。长篇可分批建立可回溯进展，跨段判断回读相关原文；不把抽样当成全读。
2. **解释机制与表达。**以事件和原文位置说明做法、可能效果及前提，区分事实、分析与推测。无真实数据不声称证明了追读、销量或爆款原因。
3. **提炼并对照。**按 [学习成果](references/learning-results.md) 区分通用方法候选、特定技巧及待验证发现。读取相关正式规则后再判断已覆盖、补充、合并、替换、删减或放宽，不把学习变成不断加禁令。
4. **按所选路径写例文。**参考路径先列原文依据，再完整呈现按原文文风与格式组织的原创例文，随后逐项说明具体方法、格式及例文对应处；不在正文中插入讲解。适配路径依下节执行。结构发现可先给原创章段方案，再写关键场景，说明短片段尚未验证的长期效果。
5. **提出可审阅调整。**呈现拟调整位置、完整文字、适用范围和状态。获本人明确同意后按 [同意与整合](references/approval-and-integration.md) 完成；同一份明确获准提案不重复要求确认。

## 两条试写路径的规则

**参考写法示范：**完全依 [指定原文示范规则](references/reference-style-demo.md) 执行。指定原文决定本轮示范的文风、视角、句段、对白与叙述分工、格式及收束，星栀正文的默认风格和章长不自动套入。只参照实际原文，不混其他作品或通用习惯；缺失依据必须说明，不承诺未经核实的完全一致。例文使用原创内容，随后具体解释原文方法怎样落地。本路径不自动成为本人小说事实或后续写作默认。

**星栀适配试写：**使用 [小说正文](../write-serial-fiction/SKILL.md) 的相关参考，按本书人设、关系、情绪、环境与知情范围调整方法。保留对白优先、战斗动作与后果、暧昧含蓄行动、本书视角和同场单一心理主角、留白及具体章末钩子；心理可用符合声线的第一人称口语独白。完整章正文默认2700—3300字，独立片段不强行扩章。对照只读相关规则，不加载全部声线和例文。

比较两种路径时指出实际发生的视角、句式、段落和收束差异，不把参考版先改成星栀版再声称完成参照。需要适配同一方法前后效果时保持同一原创情境，不故意把原版写差。

## 成果衔接与交付

按学习成果参考组织阅读范围、有关角度的拆解、方法与条件、对应路径的例文和具体说明、现有规则对照、必要的完整调整提案与当前状态。参考模式的讲解明确对应原文位置和例文句段，不能只说“更有生活感”或“节奏更好”。

跨章节奏、闭环和升级方法可交给 [章纲与节奏](../build-novel/SKILL.md) 制成原创章段方案，仍遵守来源范围、本书资料及授权。短例文不能证明全卷兑现和长期效果。

未批准成果只作候选或本轮明确要求的试验，不默认用于后续正文或章纲；正式获准的方法按适用条件调用。记录按已确认的插件包外学习目录保存；没有合适位置时在对话交付并说明未保存。普通写作不自动附拆解报告、维护阶段档案或增加检查模块。


## 参考研究与新书构建

用户明确希望参考同类作品构建新书时，配合 [构建全新小说](../build-novel/SKILL.md) 的参考研究流程。只给作品名称时可按用户意图使用实际联网工具核实资料和寻找可读原文，注明来源与实际范围；只有简介就分析其能支持的定位和框架，不假装读过章节。

这一组合任务按用户要求提供有关框架、人物、主要矛盾、阶段和节奏的分析，再形成可比较的原创方向；未要求例文时不强制试写或插件规则提案。需要参考文风示范时继续本技能原有路径。用户选定的方向交回构建流程接着完善，复用已知题材、设定和答案，不重新问整套问卷。

本书的创作选择与永久插件规则更新分开；参考分析和暂定方案仍保留来源范围与状态。单独拆书任务继续按本技能原有交付规则执行。
